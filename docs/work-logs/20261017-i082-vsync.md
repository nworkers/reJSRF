# 작업 로그: 호스트 vsync와 가상 vblank 시계 맞춤 (issue #82)

설계: [20261017-i082](../design/20261017-i082-vsync.md) · 작업 지시: [20261017-i082](../work-orders/20261017-i082-vsync.md)

## 한 일

1. `include/rexbox/platform/display.h`: `VsyncMode`(off/on/adaptive), `DisplayConfig.vsync`(기본 adaptive), `DisplayInfo.swap_interval`, `DisplayInfo.refresh_hz`.
2. `display_sdl.cpp`
   * 보이는 창: adaptive면 swap interval -1을 시도하고, 안 되면 1. on이면 1. 숨긴 창이나 off는 0.
   * `UpdateRefreshLocked`: 모니터 주사율(numerator/denominator가 있으면 그것으로). 생성, 크기 변경, `SDL_EVENT_WINDOW_DISPLAY_CHANGED` 때 읽는다.
3. `d3d8_device`: `REXBOX_VSYNC` 읽기. `[d3d8] vsync: swap interval N, monitor F Hz` 보고.
4. `d3d8_vblank`
   * 기준 시각에 위상(`g_phase`)을 더할 수 있게 했다. tick 계산(`Base`, `CountAt`)과 `RasterPosition`이 이를 따른다.
   * `AlignVerticalBlank(t)`: 현재 tick 번호를 유지한 채, 다음 tick이 호스트의 다음 귀선 3 ms 앞에 오도록 옮긴다. `VerticalBlankRate()`도 더했다.
5. `d3d8_gl_targets`: present에서 swap 시간을 잰다. swap interval이 0이 아니고, 주사율이 게스트와 1 Hz 안이고, swap이 1 ms 이상 막혔으면 맞춘다. 처음 맞출 때 한 번 보고한다.
6. 문서: 가이드, `ARCHITECTURE.md`.

# Work log: host vsync and aligning the virtual vblank clock (issue #82)

Design: [20261017-i082](../design/20261017-i082-vsync.md) · Work order: [20261017-i082](../work-orders/20261017-i082-vsync.md)

## Done

1. `include/rexbox/platform/display.h`: `VsyncMode` (off/on/adaptive), `DisplayConfig.vsync` (default adaptive), `DisplayInfo.swap_interval`, `DisplayInfo.refresh_hz`.
2. `display_sdl.cpp`
   * Visible windows: adaptive tries swap interval -1 and falls back to 1; on sets 1. Hidden windows and off get 0.
   * `UpdateRefreshLocked`: the monitor's refresh (from numerator/denominator when present), read on creation, resize and `SDL_EVENT_WINDOW_DISPLAY_CHANGED`.
3. `d3d8_device`: reads `REXBOX_VSYNC` and reports `[d3d8] vsync: swap interval N, monitor F Hz`.
4. `d3d8_vblank`
   * The base time takes a phase (`g_phase`); tick arithmetic (`Base`, `CountAt`) and `RasterPosition` follow it.
   * `AlignVerticalBlank(t)` moves the phase so the next tick comes 3 ms before the host's next blank, keeping the current tick number. `VerticalBlankRate()` added.
5. `d3d8_gl_targets`: present times the swap and aligns when the swap interval is non-zero, the refresh is within 1 Hz of the guest's, and the swap blocked for 1 ms or more; the first alignment is reported once.
6. Documents: the guide, `ARCHITECTURE.md`.
