# 작업 로그: MXCSR 모델링과 SSE 정수 변환의 반올림 (issue #48)

설계: [20261014-i048](../design/20261014-i048-mxcsr.md) · 작업 지시: [20261014-i048](../work-orders/20261014-i048-mxcsr.md) · 분석: [unlifted-instructions](../analysis/unlifted-instructions.md)

## 한 일

1. `sub_0015F0F0`을 읽었다. MXCSR을 저장하고, RC가 nearest가 아니면 `0x8000FFFF`를 돌려준다.
2. lifter를 보다가 `cvtss2si`/`cvtsd2si`가 C 캐스트(버림)로 번역되는 것을 찾았다.
   * 게임에 `cvtss2si` 6곳, `cvttss2si` 4곳이 있다.
   * `cvtsd2si`는 xmm 원본에서 float 칸(`.f[0]`)을 읽고 있었다(게임에는 없음).
3. **xboxrecomp fork**: `fix/mxcsr`(`dbae155`, upstream main 기반)를 만들고 `rejsrf`에 합쳤다(`c345158`). upstream PR은 보류한다.
   * `g_mxcsr`(TLS, 0x1F80)를 두었다. 정의 위치는 `xbox_memory_layout.c`, 새 게임 템플릿, conformance 하네스 세 곳이다.
   * `stmxcsr`/`ldmxcsr`를 번역하고 `_EFLAGS_PRESERVE`에 넣었다.
   * `recomp_cvt_si32`를 두었다. RC 반올림(`recomp_frndint` 재사용), CVTT 버림, integer indefinite를 처리한다.
   * `test_lifter_mxcsr.py`를 더했다(번역 결과 문자열, 런타임 검사).
4. **reJSRF**: `recomp_abi.c`에 `g_mxcsr`를 정의했다. `rexbox_recomp_reset_thread`가 0x1F80으로 초기화한다. 서브모듈을 올리고 다시 생성했다(lift 60초).
5. **fork push**:
   * submodule의 원격은 HTTPS인데 이 PC에 인증 정보가 없다. 그래서 첫 push가 인증 입력을 기다리며 멈췄다.
   * 멈춘 작업을 끝내고, SSH 주소로 `fix/mxcsr`와 `rejsrf`를 push했다. 원격 설정은 바꾸지 않았다.

* 런타임 검사는 cc/gcc/clang이 없어 pytest에서 건너뛴다. 같은 C 원본을 cl로 따로 빌드해 돌렸다.

* Debug 빌드는 하지 않았다. 생성 코드가 바뀌었으므로 PR CI(Debug·Release)로 확인한다.

## 남은 것

* 남은 34종(약 160곳)의 정적 분류: 함수 소속, HLE 대체 여부, 도달 가능성.
* `sub_0015F0F0`의 정체.
* `cvtps2pi`(`MMX_CVT_F2I`)는 여전히 호스트 MXCSR을 따른다(게임에는 없음).

# Work log: modelling MXCSR, and rounding in SSE integer conversions (issue #48)

Design: [20261014-i048](../design/20261014-i048-mxcsr.md) · Work order: [20261014-i048](../work-orders/20261014-i048-mxcsr.md) · Analysis: [unlifted-instructions](../analysis/unlifted-instructions.md)

## Done

1. Read `sub_0015F0F0`: it stores MXCSR and returns `0x8000FFFF` unless RC is nearest.
2. While reading the lifter, found that `cvtss2si`/`cvtsd2si` were a C cast (truncation).
   * The title has 6 `cvtss2si` and 4 `cvttss2si` sites.
   * `cvtsd2si` from an xmm register read the float lane (`.f[0]`); the title has none.
3. **xboxrecomp fork**: `fix/mxcsr` (`dbae155`, based on upstream main), merged into `rejsrf` (`c345158`). The upstream PR is held.
   * `g_mxcsr` (TLS, 0x1F80), defined in `xbox_memory_layout.c`, the new-game template and the three conformance harnesses.
   * `stmxcsr`/`ldmxcsr` translated and added to `_EFLAGS_PRESERVE`.
   * `recomp_cvt_si32`: RC rounding (reusing `recomp_frndint`), truncation for CVTT, the integer indefinite.
   * New `test_lifter_mxcsr.py` (emitted text and a runtime check).
4. **reJSRF**: `recomp_abi.c` defines `g_mxcsr`, and `rexbox_recomp_reset_thread` sets it to 0x1F80. The submodule moved up and the code was regenerated (lift 60 s).
5. **Fork push**:
   * The submodule's remote is HTTPS, and this PC has no credentials for it, so the first push hung waiting for a login.
   * That task was stopped, and `fix/mxcsr` and `rejsrf` were pushed through the SSH URL. The remote setting was not changed.

## Verification

The table in the Korean section applies:

* xboxrecomp `tools/recomp` tests (pytest in a scratchpad venv): `fix/mxcsr` 460 passed, 39 skipped; `rejsrf` 469 passed, 40 skipped.
* Runtime check (`recomp_cvt_si32`, cl x86 `/std:c11`): passes.
* Regenerated summary: 35 → 34 unimplemented kinds (`stmxcsr` gone).
* Win32 Release build: zero warnings.
* Probes 56/0, 116/0, 48/0; decomp check 6/0; d3d8 check 14,018/0.
* Demo run (to frame 3,000): no `untranslated instruction` warning.
* Frames 300–1,800, 2,800 and 3,000: byte-identical to v0.0.19.
* With no cc/gcc/clang, pytest skips the runtime check; the same C source was built with cl and run separately.
* `pytest` and `capstone` went into a scratchpad venv, not the user's Python. Run with `unittest` in the user's Python, 13 modules that import pytest fail to import, which is unrelated to this change.
* No Debug build was made here; the generated code changed, so the PR's CI (Debug and Release) checks it.
