# Work log: VBlank wait on/off (issue #95)

Design: [20261018-i095](../design/20261018-i095-vblank-wait.md) · Work order: [20261018-i095](../work-orders/20261018-i095-vblank-wait.md)

## Done

1. `d3d8_vblank`
   * Off, the clock runs at 10 kHz (`kUnpacedHertz`). A switch or a refresh change retimes it (`Retime`), keeping the current tick count.
   * No `AlignVerticalBlank` while off.
   * Skipping only the waits was tried first and stalled about 6 s in every 1000-frame window (design section 2).
2. `d3d8_display`: `DisplayDefaults.vblank_wait`, `VerticalBlankWaitEnabled`/`SetVerticalBlankWaitEnabled`.
3. Settings: `VBlankWait` in `rejsrf.ini`, applied at start; a checkbox with a tooltip under VSync in the Graphics tab.
4. Documents: the guide, `ARCHITECTURE.md`.
