# Issue #5 work log — clearing the Node.js 20 deprecation warning in CI

Work order: [20261012-i005](../work-orders/20261012-i005-ci-node24.md)

The first CI run (PR #4) carried a "Node.js 20 is deprecated … actions/checkout@v4" annotation. Moving `actions/checkout` to v7 (`using: node24`, the version rePIU uses) clears it. A `workflow_dispatch` trigger was added so CI can run on a task branch without a pull request (`gh workflow run ci.yml --ref <branch>`). Verified: before the change (run 38156302673) CI passed with one Node.js 20 annotation; after it (run 38156518907, manual run on the task branch) Debug and Release pass with no annotations.
