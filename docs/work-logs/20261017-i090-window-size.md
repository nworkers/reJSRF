# Work log: Window Size in the settings menu (issue #90)

Design: [20261017-i090](../design/20261017-i090-window-size.md) · Work order: [20261017-i090](../work-orders/20261017-i090-window-size.md)

## Done

1. Platform (`display.h`, `display_sdl.cpp`): `kMaxWindowScale` (3, tied to Alt+1..3 by a `static_assert`), `SetWindowScale`, `WindowScale`, `GetPictureSize`.
2. `OpenDisplay` passes `DisplayDefaults.window_scale` (default 2) as `DisplayConfig.scale`.
3. Settings: `WindowScale` (1-3) in `rejsrf.ini`. A "Window Size" combo at the top of the menu's Graphics tab; a size that is not a preset reads `Custom` or `Fullscreen`; picking a preset leaves fullscreen; sizes set with Alt+1/2/3 are saved too.
4. Documents: the guide.

| Check | Result |
|---|---|
| Release and Debug builds | no warnings or errors |
| The menu (visible window, during the demo) | `Window Size  2x (1280x960)` at the top of the Graphics tab, Rendering Resolution below it |
| User play | waiting for the user's check |
