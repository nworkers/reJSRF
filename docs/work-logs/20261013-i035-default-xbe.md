# Issue #35 작업 로그 — 게임 디렉터리의 default.xbe, 다른 XBE는 --xbe

작업 지시: [20261013-i035](../work-orders/20261013-i035-default-xbe.md) · 설계: [20261013-i035](../design/20261013-i035-default-xbe.md)

## 요약

`rejsrf <게임 디렉터리>`는 `default.xbe`를 읽고, `--xbe <파일>`로 다른 XBE를 읽는다. i033의 자동 선택(디렉터리에서 US판 찾기)은 없앴다. 문서 예시는 Sega GT·JSRF 합본 디스크를 떠올리게 하는 `SegaJSRF.xbe`로 썼다. 기준 덤프의 `default.xbe`는 일본판이다. 그래서 옵션 없이 실행하면 일본판을 읽고 "`--xbe`로 US판을 지정하라"는 안내와 함께 멈춘다. 가이드에 이 점을 적었다.

# Issue #35 work log — default.xbe from the game directory, --xbe for another XBE

Work order: [20261013-i035](../work-orders/20261013-i035-default-xbe.md) · Design: [20261013-i035](../design/20261013-i035-default-xbe.md)

## Summary

`rejsrf <game directory>` loads `default.xbe`, and `--xbe <file>` loads another XBE. i033's automatic choice (finding the US build in the directory) is gone. The docs' example is `SegaJSRF.xbe`, which suggests a disc combining Sega GT and JSRF. In the reference dump `default.xbe` is the Japan build. So with no option the app loads the Japan build and stops with a hint to name the US build with `--xbe`, and the guide says so.
