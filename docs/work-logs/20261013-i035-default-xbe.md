# Issue #35 작업 로그 — 게임 디렉터리의 default.xbe, 다른 XBE는 --xbe

작업 지시: [20261013-i035](../work-orders/20261013-i035-default-xbe.md) · 설계: [20261013-i035](../design/20261013-i035-default-xbe.md)

## 요약

`rejsrf <게임 디렉터리>`는 `default.xbe`를 읽고, `--xbe <파일>`로 다른 XBE를 읽는다. i033의 자동 선택(디렉터리에서 US판 찾기)은 없앴다. 문서 예시는 Sega GT·JSRF 합본 디스크를 떠올리게 하는 `SegaJSRF.xbe`로 썼다. 재컴파일 코드는 US판에서 만들었으므로, `default.xbe`가 다른 판이면 앱은 그것을 읽고 "`--xbe`로 US판을 지정하라"는 안내와 함께 멈춘다. 가이드에 이 점을 적었다. 검증에는 `default.xbe`가 US판인 게임 디렉터리를 썼다.

# Issue #35 work log — default.xbe from the game directory, --xbe for another XBE

Work order: [20261013-i035](../work-orders/20261013-i035-default-xbe.md) · Design: [20261013-i035](../design/20261013-i035-default-xbe.md)

## Summary

`rejsrf <game directory>` loads `default.xbe`, and `--xbe <file>` loads another XBE. i033's automatic choice (finding the US build in the directory) is gone. The docs' example is `SegaJSRF.xbe`, which suggests a disc combining Sega GT and JSRF. The recompiled code comes from the US build, so when `default.xbe` is another build the app loads it and stops with a hint to name the US build with `--xbe`, and the guide says so. Verification used a game directory whose `default.xbe` is the US build.

## Verification

|---|---|
| none | usage; 2 |
| `LICENSE` | `is not a directory`; 1 |
| `docs` | `has no default.xbe (XBE files there: none)`; 1 |
| `"roms\Jet Set Radio Future"` | `xbe: USA (region 1) (default.xbe)`; the 2,700th present (attract demo); 50 s watchdog |
| `… --xbe <a Japan XBE>` | `xbe: Japan (region 2)`; the hint, then stops; 0 |
| `… --xbe nope.xbe` | `has no nope.xbe (XBE files there: …)`, listing the folder's `.xbe` files; 1 |
