# 작업 로그: XMM SSE2 intrinsic을 선택 사항으로 (issue #44 후속)

설계: [20261013-i044 §3.4](../design/20261013-i044-recomp-codegen.md) · 작업 지시: [20261013-i044-xmm-sse2-opt-in](../work-orders/20261013-i044-xmm-sse2-opt-in.md)

## 배경

* Release 빌드가 configure에서 멈췄다. `gen/jsrf_us/gen`이 v0.0.18 이전 xboxrecomp로 생성되어 `recomp_types.h` 해시가 달랐다. 재생성으로 해결된다(이 작업의 변경과는 무관).
* 사용자 결정(2026-10-13): fork의 SSE2 XMM intrinsic은 기본으로 끄고 필요할 때만 켠다. 성능 작업은 HLE에 집중한다.

## 한 일

1. `src/rexbox/CMakeLists.txt`에 `REXBOX_RECOMP_XMM_SSE2`(기본 `OFF`)를 추가했다. `OFF`이면 `rexbox_recomp`가 `RECOMP_XMM_PORTABLE`를 PUBLIC으로 정의한다.
2. 생성 코드를 다시 만들었다(lift 70초, 전체 약 1분 45초).
3. Win32 Release를 빌드했다. 생성된 `rexbox_recomp`, `rejsrf_recomp`, `rejsrf_game` 프로젝트에 `RECOMP_XMM_PORTABLE`가 들어갔다.
   * 첫 빌드는 링크에서 `LNK1104`(`rejsrf.exe`를 열 수 없음)로 실패했다. 다시 빌드하자 통과했다. 그때 실행 중인 프로세스는 없었으므로 잠깐 파일이 잠겼던 것으로 본다.

## 검증

| 검증 | 결과 |
|---|---|
| kernel probe | 56 check, 0 failure |
| D3D8 probe | 116 check, 0 failure |
| DSOUND probe | 48 check, 0 failure |
| decomp check | 6 case, 0 difference |
| d3d8 check | 14,018 case, 0 difference |
| 숨긴 창·오디오 없음 60초 실행 | 프레임 3,000까지 60 Hz(500 프레임당 약 8.3초), 오류 없음 |

* Debug 빌드와 `ON` 경로는 다시 빌드하지 않았다. `ON`은 헤더와 생성 코드가 v0.0.18과 같으므로 그때의 검증이 적용된다.
* 성능은 재지 않았다. 기본 빌드는 i044 §4의 XMM 이득(약 -12%)을 잃는 것으로 본다(**추정**).

## 남은 것

* SSE2 경로가 다시 필요해지면 `cmake -DREXBOX_RECOMP_XMM_SSE2=ON`으로 켠다.

# Work log: XMM SSE2 intrinsics made opt-in (issue #44 follow-up)

Design: [20261013-i044 §3.4](../design/20261013-i044-recomp-codegen.md) · Work order: [20261013-i044-xmm-sse2-opt-in](../work-orders/20261013-i044-xmm-sse2-opt-in.md)

## Background

* The Release build stopped at configure: `gen/jsrf_us/gen` had been generated by the xboxrecomp before v0.0.18, so its `recomp_types.h` hash differed. Regenerating fixes it (unrelated to this change).
* User decision (2026-10-13): the fork's SSE2 XMM intrinsics are off by default and turned on only when needed. Performance work concentrates on the HLE.

## Done

1. Added `REXBOX_RECOMP_XMM_SSE2` (default `OFF`) to `src/rexbox/CMakeLists.txt`. When it is `OFF`, `rexbox_recomp` defines `RECOMP_XMM_PORTABLE` as PUBLIC.
2. Regenerated the generated code (lift 70 s, about 1 min 45 s in total).
3. Built Win32 Release. The generated `rexbox_recomp`, `rejsrf_recomp` and `rejsrf_game` projects carry `RECOMP_XMM_PORTABLE`.
   * The first build failed at link with `LNK1104` (cannot open `rejsrf.exe`) and passed when run again. No process was running then, so the file was taken to be briefly locked.

## Verification

The table in the Korean section applies:

* kernel probe 56/0, D3D8 probe 116/0, DSOUND probe 48/0, decomp check 6/0, d3d8 check 14,018/0.
* A 60-second run with a hidden window and no audio reached frame 3,000 at 60 Hz (about 8.3 s per 500 frames) with no errors.
* Debug and the `ON` path were not rebuilt. `ON` leaves the header and generated code as in v0.0.18, so that version's verification applies.
* Performance was not measured. The default build is taken to give up i044 §4's XMM gain (about -12%) (**inferred**).

## Remaining

* If the SSE2 path is needed again, turn it on with `cmake -DREXBOX_RECOMP_XMM_SSE2=ON`.
