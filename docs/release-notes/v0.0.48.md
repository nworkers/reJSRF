## reJSRF v0.0.48

이전 릴리스 **v0.0.47** 이후의 변경입니다(issue #111). **설정 메뉴 Info 탭에 공용 런타임 rexbox의 버전과 커밋을 표시하고, Stats 창의 그래프를 절반 높이로 줄였습니다.** 게임 동작은 바뀌지 않았습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#111](https://github.com/nworkers/reJSRF/issues/111) | Info 탭에 rexbox 버전과 커밋, Stats 그래프 높이 절반 | `3205577` |

### 바뀐 것

* **Info 탭**([설계 i111](../design/20261023-i111-rexbox-version-info.md))
  * `Game` 바로 아래에 `rexbox`(버전, 예: `v0.0.9`)와 `rexbox commit`(예: `b2f2653`) 두 줄을 더했다.
  * 값은 빌드할 때마다 `third_party/rexbox`의 `VERSION`과 git 커밋에서 읽는다(`src/app/build_stamp.cmake`). submodule을 옮기면 다시 configure하지 않아도 다음 빌드에 반영된다. submodule 안에 커밋하지 않은 변경이 있으면 `+modified`가 붙는다.
* **Stats 창**: FPS, Memory, Video memory 그래프의 높이를 모두 절반(64 → 32, OSD 배율 곱)으로 줄였다. 눈금 이름표는 겹치지 않는다.

### 확인한 것

| 실행 화면 | 창 캡처로 Info 탭의 두 줄과 절반 높이 그래프 확인 |

## reJSRF v0.0.48 (English)

Changes since **v0.0.47** (issue #111). **The settings menu's Info tab shows the shared runtime rexbox's version and commit, and the Stats window's graphs are half as tall.** Game behaviour is unchanged.

Resolved issue: #111, the rexbox version and commit in the Info tab and the Stats graphs at half height; commit `3205577`.

Changes:
* **Info tab** ([design i111](../design/20261023-i111-rexbox-version-info.md))
  * Two rows right below `Game`: `rexbox` (the version, e.g. `v0.0.9`) and `rexbox commit` (e.g. `b2f2653`).
  * The values are read on every build from `third_party/rexbox`'s `VERSION` and git commit (`src/app/build_stamp.cmake`), so a moved submodule shows in the next build without a reconfigure; uncommitted changes inside the submodule add `+modified`.
* **Stats window**: the FPS, Memory and Video memory graphs are all half as tall (64 → 32, times the OSD scale); their tick labels do not overlap.

Verified: Win32 x86 Release with zero warnings; the generated header's rexbox version and commit equal the submodule's. A window capture of the running app shows the two Info rows and the half-height graphs. User: approved the merge.
