## reJSRF v0.0.19

이전 릴리스 **v0.0.18** 이후의 변경입니다(issue #46, #44 후속). **D3D8 HLE의 변경 감지가 싸져, 오프닝 3D 데모의 프레임당 CPU 시간이 약 11% 줄었습니다.** lift 코드의 SSE2 XMM 도우미는 이제 선택 사항입니다(기본 끔).

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#46](https://github.com/nworkers/reJSRF/issues/46) | HLE 비용 줄이기: 게스트 메모리 쓰기 버전, 그리기 경로 조회 | `710c927` |
| [#44](https://github.com/nworkers/reJSRF/issues/44) 후속 | SSE2 XMM 도우미를 선택 사항으로(CMake `REXBOX_RECOMP_XMM_SSE2`, 기본 `OFF`) | `08c70e0` |

### 바뀐 것

* **게스트 메모리 쓰기 버전.** 게스트 메모리를 OS 쓰기 기록과 함께 할당합니다(Win32 `GetWriteWatch`). 8 KiB 이상인 정점·인덱스 범위는 쓰이지 않았으면 비교하지 않습니다. 프레임당 비교량이 4.3 MB에서 1.4 MB로 줄었습니다.
* **그리기 경로.** 정점 셰이더 상수 버전으로 uniform 비교를 건너뜁니다. 렌더 타깃 조회 결과를 기억합니다. 한 번만 하는 보고와 경고가 잠금 없이 돌아갑니다.
* **프로필.** `REXBOX_D3D8_PROFILE`이 캐시 사본과 비교한 바이트와 범위 수(`compared`)를 보여 줍니다.
* **SSE2 XMM 도우미.** 기본으로 끕니다. `cmake -DREXBOX_RECOMP_XMM_SSE2=ON`으로 켜면 v0.0.18과 같습니다(재생성 불필요). 기본 빌드는 v0.0.18의 XMM 이득을 쓰지 않습니다.
* **측정.** present 스레드 CPU 시간(ms/프레임, 번갈아 3회 평균, Ryzen 5 5600X)입니다. 그리기 483개 구간 5.42 → 4.83, 네 구간 합 19.38 → 17.19.

## reJSRF v0.0.19 (English)

Changes since **v0.0.18** (issue #46, and a follow-up to #44). **The D3D8 HLE's change detection is cheaper, cutting the CPU time per frame of the opening 3D demo by about 11%.** The lifted code's SSE2 XMM helpers are now opt-in (off by default).

Resolved issues:
* #46, cheaper HLE work (guest memory write versions, draw-path lookups), commit `710c927`.
* #44 follow-up, SSE2 XMM helpers made opt-in (CMake `REXBOX_RECOMP_XMM_SSE2`, default `OFF`), commit `08c70e0`.

Changes:
* **Guest memory write versions:** guest memory is allocated with OS write tracking (Win32 `GetWriteWatch`). Vertex and index ranges of 8 KiB or more are not compared while unwritten. The bytes compared per frame fell from 4.3 MB to 1.4 MB.
* **Draw path:** a vertex shader constant version skips the uniform comparison, the render-target lookup is remembered, and log-once reports and warnings return without locking.
* **Profile:** `REXBOX_D3D8_PROFILE` shows the bytes and ranges compared with cached copies (`compared`).
* **SSE2 XMM helpers:** off by default. `cmake -DREXBOX_RECOMP_XMM_SSE2=ON` restores v0.0.18's behavior (no regeneration needed). The default build gives up v0.0.18's XMM gain.
* **Measurement:** presenting-thread CPU time (ms per frame, mean of three alternating runs, Ryzen 5 5600X). 483-draw window 5.42 → 4.83; sum of four windows 19.38 → 17.19.

Verified:
* Win32 x86 Release: regeneration and build with zero warnings; probes 56/0, 116/0, 48/0; d3d8 check 14,018/0; decomp check 6/0.
* Win32 x86 Debug: the changed libraries and the probes build; kernel and D3D8 probes pass.
* Picture: logo frames 300–1,800 byte-identical to the baseline; the demo shows the same scene (a faster build advances it differently, so the camera differs slightly).
