## reJSRF v0.0.25

이전 릴리스 **v0.0.24** 이후의 변경입니다(issue #58). **늦게 생긴 본문의 조건 분기 대상과, 데이터에서만 불리던 함수를 되찾았습니다.** 그 과정에서 드러난 lifter의 중첩 switch 공백도 고쳤습니다. 데이터에서만 참조되는데 lift되지 않은 함수는 이제 없습니다.

| [#58](https://github.com/nworkers/reJSRF/issues/58) | 거절되던 포인터 seed `0x1FD10`, `0x20F10` | `6fa3ede` |

### 바뀐 것

* **디스어셈블러**(xboxrecomp fork, upstream [PR #200](https://github.com/sp00nznet/xboxrecomp/pull/200)에 덧붙임)
  * 늦게 생긴 본문에서 빈 구간으로 가는 `jcc`도 받습니다.
  * 받는 조건은 기존과 같고, 간접 `jmp`로 끝나는 블록을 더했습니다.
* **lifter**(같은 PR)
  * 복구된 switch case 함수 안의 중첩 switch가 case 진입점을 얻습니다.
  * 이것이 빠지면 이번 디스어셈블러 수정이 디스패치 항목 12개를 잃게 했습니다.
* **seed**
  * `0x1783FE`, `0x1296C7`을 넣었습니다.
  * 표 `0x1EBC80`의 `0x1FD10`·`0x20F10`은 인라인 바이트 표 뒤에 있어 포인터 seed가 계속 거절되고 있었습니다. `observed` seed로 넣었습니다.
* **수치**:
  * 미해결 스텁 76 → 74
  * 함수(디스패치) 9,203 → 9,215
  * 거절된 seed 0, 포인터 후보 0

## reJSRF v0.0.25 (English)

Changes since **v0.0.24** (issue #58). **Conditional-branch targets of late bodies, and functions called only from data, are recovered.** A lifter gap with nested switches, found on the way, is fixed too. No function referenced only from data is left unlifted.

Resolved issue #58:
* `jcc` targets of late bodies (`0x1783FE`, `0x1296C7`) and nested switches inside recovered switch arms, commit `a6513a8`
* the refused pointer seeds `0x1FD10` and `0x20F10`, commit `6fa3ede`

Changes:
* **Disassembler** (xboxrecomp fork, added to upstream [PR #200](https://github.com/sp00nznet/xboxrecomp/pull/200)):
  * A `jcc` from a late body into a gap is taken too.
  * The acceptance test is the existing one, extended to blocks ending in an indirect `jmp`.
* **Lifter** (same PR):
  * A nested switch inside a recovered switch arm gets arm entries.
  * Without this, the disassembler change lost 12 dispatch entries.
* **Seeds:**
  * `0x1783FE` and `0x1296C7` are seeded.
  * `0x1FD10` and `0x20F10` in table `0x1EBC80` follow inline byte tables, so their pointer seeds kept being refused; they are now `observed` seeds.
* **Figures:**
  * unresolved stubs 76 → 74
  * functions (dispatch) 9,203 → 9,215
  * no refused seeds, no pointer candidates

Verified:
* Win32 x86 Debug and Release with zero build warnings
* kernel probe 56/56, D3D8 probe 116/116, DSOUND probe 48/48
* d3d8 check 14,018 cases with 0 differences; decomp check 6/6
* xboxrecomp fork: `pytest tools/recomp tools/disasm`, 548 passed
* demo: no `[recomp]` reports, six frames identical (one timing jitter aside)
* play (user): no `[recomp]` reports; a later hang is left to the next task (D3D8)
* CI on the pull request
