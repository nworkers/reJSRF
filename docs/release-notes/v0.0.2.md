## reJSRF v0.0.2

이전 릴리스 **v0.0.1** 이후의 변경입니다(issue #5, #6). **부팅이 GPU 레지스터 fault 대신 D3D8의 첫 API 호출에서 그 이름을 알리며 멈춥니다.** D3D8 함수 136개가 모두 HLE 진입점을 거치게 되어, 다음 단계(D3D8 HLE 구현)의 출발점이 마련됐습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#5](https://github.com/nworkers/reJSRF/issues/5) | CI의 Node.js 20 폐기 경고 해소(`actions/checkout@v7`), 작업 브랜치 수동 실행 | `70a6fc2`, `806ed25`, `f4ddefb` |
| [#6](https://github.com/nworkers/reJSRF/issues/6) | XbSymbolDatabase로 XDK 함수 식별, D3D8 호출을 HLE로 연결 | `2599e03` |

### 바뀐 것

* **XDK 함수 식별.** 새 도구 `rexbox_xdk_symbols`가 XbSymbolDatabase(MIT, submodule)로 XBE 안의 XDK 함수·변수를 찾습니다. US판에서 363개, jsrf-recomp의 D3D8 진입점 103개 중 98개와 일치합니다.
* **D3D8 → HLE.** `regenerate.py`가 D3D8·D3D8LTCG 함수 136개마다 override를 생성해 직접·간접 호출을 모두 `rexbox_hle_enter`로 보냅니다. 구현이 없으면 `stopped at unimplemented XDK function D3D8 <이름>`으로 멈춥니다. `REXBOX_HLE_FALLBACK=lifted`는 원본을 실행하며 호출 순서를 기록하는 진단 모드입니다.
* **빌드 순서.** 처음 생성할 때는 `rexbox_xdk_symbols`를 먼저 빌드합니다(가이드 참고).
* **CI.** `actions/checkout@v7`(Node.js 24). `gh workflow run ci.yml --ref <branch>`로 작업 브랜치에서도 돌릴 수 있습니다.

## reJSRF v0.0.2 (English)

Changes since **v0.0.1** (issues #5, #6). **Boot now stops at D3D8's first API call, naming it, instead of faulting on a GPU register.** All 136 D3D8 functions go through HLE entry points, which sets up the next step (implementing the D3D8 HLE).

Resolved issues: #5 the CI Node.js 20 deprecation warning (`actions/checkout@v7`) and manual runs on task branches, `70a6fc2`, `806ed25`, `f4ddefb`; #6 XDK function identification with XbSymbolDatabase and D3D8 calls routed to the HLE, `2599e03`.

Changes: the new tool `rexbox_xdk_symbols` finds XDK functions and variables in an XBE with XbSymbolDatabase (MIT, submodule): 363 in the US build, agreeing with 98 of jsrf-recomp's 103 D3D8 entry points. `regenerate.py` generates an override for each of the 136 D3D8/D3D8LTCG functions so direct and indirect calls reach `rexbox_hle_enter`, which stops with `stopped at unimplemented XDK function D3D8 <name>` when there is no implementation; `REXBOX_HLE_FALLBACK=lifted` is a diagnostic mode that runs the originals and records the call order. The first generation needs `rexbox_xdk_symbols` built first (see the guide). CI uses `actions/checkout@v7` (Node.js 24) and can run on a task branch with `gh workflow run ci.yml --ref <branch>`.

Verified on Win32 x86 Debug and Release: zero build warnings, `rexbox_kernel_probe` 27/27, `rejsrf_decomp_check` 6/6, boot stopping at `Direct3D_GetAdapterCount`; CI (manual run on the task branch) passing Debug and Release with no Node.js 20 annotation.
