### 바뀐 것

* **저장 경로.**
  * 항목 파일은 `close()` 뒤 상태까지 확인한 다음에만 이름을 바꿉니다. 잘린 파일이 정식 항목이 되던 경로를 막았습니다.
  * 쓰기나 이름 바꾸기가 실패하면 임시 파일을 지우고 한 번 보고합니다.
* **진단.** `REXBOX_D3D8_PROFILE`의 프로그램 줄이 저장 수와 시간을 따로 냅니다(`stored N, X ms`).
* **측정**(NVIDIA GeForce RTX 4090):
  * 컴파일은 개당 약 0.6 ms로, 바이너리 불러오기(약 0.8~1.2 ms)보다 쌉니다.
  * 첫 실행은 저장 때문에 개당 약 1.8 ms가 더 듭니다.
  * Intel HD 620의 이득(약 2.4초 → 약 0.13초)이 훨씬 커서, 캐시는 모든 드라이버에서 기본으로 켭니다.
* **분석.** 데모 중 게임의 `NtWriteFile`은 부팅 때 1 MB 두 번(각 약 0.3 ms)뿐이고, 느린 프레임과 겹치지 않습니다.

## reJSRF v0.0.23 (English)

Changes since **v0.0.22** (issue #51 follow-up). **The shader cache's store path no longer misses failures, and its cost is measured.** The title's file writes were also confirmed not to cause the demo's stutter.

Resolved issue #51 (follow-up):
* store-path cost measured and failures handled, commit `dc85796`
* guest file writes checked, cache-on-by-default decision recorded, commit `84c92c2`

Changes:
* **Store path:**
  * An entry file is renamed only after `close()` and a check of the stream state, closing the path that made a truncated file the entry.
  * A failure to write or rename removes the temporary file and is reported once.
* **Diagnostics:** the `REXBOX_D3D8_PROFILE` programs line reports stores and their time separately (`stored N, X ms`).
* **Measurement** (NVIDIA GeForce RTX 4090):
  * Compiling takes about 0.6 ms a program, less than loading a binary (about 0.8–1.2 ms).
  * A first run costs about 1.8 ms more a program for the stores.
  * The gain on the Intel HD 620 (about 2.4 s → about 0.13 s) is far larger, so the cache stays on by default on every driver.
* **Analysis:** during the demo the title's `NtWriteFile` runs only twice at boot (1 MB each, about 0.3 ms), away from the slow frames.

Verified on Win32 x86 Debug and Release:
* zero warnings in the changed files
* kernel probe 56/56, D3D8 probe 116/116, DSOUND probe 48/48
* d3d8 check 14,018 cases with 0 differences; decomp check 6/6
* write-denied folder and failed rename: one report each, no `.tmp`
* CI on the pull request
