## reJSRF v0.0.10

이전 릴리스 **v0.0.9** 이후의 변경입니다(issue #23, #12). **부팅이 첫 화면을 그립니다. "Presented by SEGA" 로고가 창에 나오고, 프레임 루프는 60 Hz로 돕니다.** 게임은 로고에서 다음 화면으로 넘어가지 않으며(이전과 같은 정지 지점), 사운드 `Play`는 아직 부르지 않습니다.

### 해결된 issue

|---|---|---|
| [#23](https://github.com/nworkers/reJSRF/issues/23) | D3D8 HLE 세 번째 묶음: 고정 기능 그리기를 GL로 | `b4afb9c`, `68e85ea`, `fcdfee8`, `ff6a935` |
| [#12](https://github.com/nworkers/reJSRF/issues/12) | D3D8 HLE 두 번째 묶음: 서피스, 렌더 타깃, Clear/Swap으로 첫 프레임(첫 `Swap`은 #19에서 통과, 화면 출력은 #23에서 완성) | `c552613`, `90e3e75` |

### 바뀐 것

* **라이브러리 전역.** 게임의 XDK inline이 직접 읽고 쓰는 `D3D__RenderState`, `D3D__TextureState`, `D3D__IndexData`를 HLE setter도 원본과 같은 칸에 씁니다. 그리기는 이 배열에서 상태를 읽습니다. HLE 디바이스는 원본의 기본 상태 루틴을 실행합니다.
* **GL 그리기.** `Draw*`/`*UP`가 FVF 정점과 인덱스를 게스트 메모리에서 읽습니다. 텍스처는 CPU에서 RGBA8로 풀어 캐시합니다(Morton 스위즐, DXT1/3/5, 16·32비트). 텍스처 스테이지는 GLSL로 바꾸고, 깊이·블렌드·컬링·스텐실·알파 테스트를 적용합니다. 백버퍼와 깊이 버퍼는 FBO이고, `Swap`이 창으로 blit합니다.
* **고친 것.** 인덱스 포인터가 0이던 문제(`D3D__IndexData`), 그리고 PC 비트로 읽던 `D3DCLEAR`(Xbox: 색 0xF0, 깊이 1, 스텐실 2)를 고쳤습니다.
* **수직 동기.** 가상 60 Hz vblank 시계가 `Swap`, `BlockUntilVerticalBlank`, `GetRasterStatus`를 맞춥니다. 호스트 vsync는 끕니다. 헤드리스 실행도 실제 속도로 돕니다.
* **진단.** `REXBOX_DISPLAY=hidden`(보이지 않는 창), `REXBOX_FRAME_DUMP=<n>`(BMP 덤프), `REXBOX_D3D8_TRACE=1`을 추가했습니다.
* **도구.** 새 `rexbox_d3d8_probe`(게임·GPU 불필요, CI). `rejsrf_d3d8_check`에 상태 setter의 전역 칸 비교를 더했습니다.
* **타이틀 프로파일**이 `D3D_InitializeDeviceState`(`0x001919C0`)를 바인딩합니다. 기존 체크아웃은 `regenerate.py`를 다시 실행해야 합니다(`rexbox_xdk_variables[]`가 필요).

## reJSRF v0.0.10 (English)

Changes since **v0.0.9** (issues #23 and #12). **The boot draws its first screen: the "Presented by SEGA" logo shows in the window and the frame loop runs at 60 Hz.** The game does not move past the logo (the same stopping point as before) and calls no sound `Play` yet.

Resolved issues: #23, the D3D8 HLE third batch (fixed-function drawing on GL), commits `b4afb9c`, `68e85ea`, `fcdfee8` and `ff6a935`; #12, the D3D8 HLE second batch (surfaces, render targets, Clear/Swap to the first frame; the first `Swap` was passed in #19 and the picture completed in #23), commits `c552613` and `90e3e75`.

Changes:

* **Library globals.** The HLE setters write the same slots as the originals in `D3D__RenderState`, `D3D__TextureState` and `D3D__IndexData`, which the game's XDK inlines read and write directly. Drawing reads its state from these arrays, and the HLE device runs the original default-state routine.
* **GL drawing.** `Draw*`/`*UP` read FVF vertices and indices from guest memory. Textures are decoded to RGBA8 on the CPU and cached (Morton swizzle, DXT1/3/5, 16/32-bit). Texture stages become GLSL, and depth, blend, cull, stencil and alpha test are applied. Back and depth buffers are FBOs that `Swap` blits to the window.
* **Fixes.** The null index pointer (`D3D__IndexData`), and `D3DCLEAR` read with PC bits (Xbox: color 0xF0, depth 1, stencil 2).
* **Vertical blank.** A virtual 60 Hz vblank clock paces `Swap`, `BlockUntilVerticalBlank` and `GetRasterStatus`. Host vsync is off, and headless runs also run in real time.
* **Diagnostics.** New `REXBOX_DISPLAY=hidden` (invisible window), `REXBOX_FRAME_DUMP=<n>` (BMP dumps) and `REXBOX_D3D8_TRACE=1`.
* **Tools.** A new `rexbox_d3d8_probe` (no game or GPU, runs in CI). `rejsrf_d3d8_check` now also compares the state setters' global slots.
* **Title profile.** It binds `D3D_InitializeDeviceState` (`0x001919C0`). Existing checkouts must re-run `regenerate.py` (`rexbox_xdk_variables[]` is required).

Verified on Win32 x86 Debug and Release: zero build warnings; kernel probe 42/42, DSOUND probe 48/48, D3D8 probe 73/73, decomp check 6/6; d3d8 check 14,018 cases with 0 differences; 0 pop mismatches. The boot shows the logo in the window at 60 Hz, and hidden-window frame dumps show the same logo over 145 s.
