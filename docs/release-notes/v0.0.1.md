## reJSRF v0.0.1

첫 릴리스입니다(issue #1, #2, #3). **재컴파일한 Jet Set Radio Future(US)가 Win32에서 진입점부터 실행되어 XAPI 초기화를 마치고, D3D8이 GPU를 처음 건드리는 지점까지 갑니다.** 아직 화면과 소리는 없습니다.

| [#3](https://github.com/nworkers/reJSRF/issues/3) | 커널 HLE 최소 구현: 게임 메인 스레드와 XAPI 초기화 | `0e71cfb` |

### 바뀐 것

* **구조.** `platform` → `rexbox`(타이틀 비의존 Xbox 런타임과 HLE 모듈) → `game/jsrf` → `app`. HLE는 레지스터·스레드 계약으로만 게스트에 닿고, 생성 코드의 ABI는 `rexbox_recomp` 한 곳에만 있습니다.
* **재컴파일.** `scripts/recomp/regenerate.py`가 고정된 xboxrecomp(v0.13.1)로 사용자 XBE를 `gen/`에 C로 옮깁니다(함수 8,721개). 생성 코드는 커밋하지 않습니다. 디컴파일 함수는 같은 심볼로 lift 버전을 대체하고, lift 본문은 `sub_X_gen`으로 남아 비교할 수 있습니다.
* **커널 HLE.** export 103개: 스레드(실제 KPCR/ETHREAD/TLS 배치), 동기화, 메모리, 파일(Xbox 이름공간 → 호스트 폴더), Rtl, HAL, SHA-1, 데이터 export.
* **라이선스.** xboxrecomp의 LGPL 파일은 빌드에 들어가면 configure가 실패합니다.

## reJSRF v0.0.1 (English)

The first release (issues #1, #2, #3). **Recompiled Jet Set Radio Future (US) runs on Win32 from its entry point through XAPI initialization to the point where D3D8 first touches the GPU.** There is no picture or sound yet.

Resolved issues: #1 project bootstrap (rules based on rePIU, MIT, layer structure, Win32 build skeleton, XBE analysis) `33e57b2`; #2 recompilation pipeline (the US XBE lifted to C and linked on Win32, first decompiled function) `22465bf`; #3 minimal kernel HLE (the game's main thread and XAPI initialization) `0e71cfb`.

Changes: the layering `platform` → `rexbox` (title-agnostic Xbox runtime and HLE modules) → `game/jsrf` → `app`, with HLE reaching the guest only through register and thread contracts and the generated-code ABI confined to `rexbox_recomp`; `scripts/recomp/regenerate.py` lifting the user's XBE to C in `gen/` with the pinned xboxrecomp v0.13.1 (8,721 functions, never committed), decompiled functions replacing lifted ones by symbol with the lifted body kept as `sub_X_gen`; 103 kernel exports (threads with the real KPCR/ETHREAD/TLS layout, sync, memory, files over the Xbox namespace mapped to host folders, Rtl, HAL, SHA-1, data exports); configure fails if xboxrecomp's LGPL files enter the build.

Verified on Win32 x86 Debug and Release: zero build warnings, `rexbox_kernel_probe` 27/27, `rejsrf_decomp_check` 6/6, boot reaching D3D8's read of NV2A `0xFD001804`.
