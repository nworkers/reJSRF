이전 릴리스 **v0.0.19** 이후의 변경입니다(issue #48). **매 프레임 나오던 `stmxcsr` 미번역 경고가 사라졌고, SSE 정수 변환이 하드웨어처럼 반올림합니다.** 화면은 v0.0.19와 같습니다.

### 바뀐 것

* **MXCSR.** `sub_0015F0F0`은 매 프레임 MXCSR을 저장하고, 반올림 모드가 nearest가 아니면 `E_UNEXPECTED`를 돌려줍니다. 지금까지는 `stmxcsr`가 아무것도 저장하지 않아, 메모리에 남아 있던 값으로 판정했습니다.
  * xboxrecomp fork(`rejsrf` `c345158`)가 게스트 MXCSR을 TLS `g_mxcsr`(리셋 0x1F80)로 다룹니다. `stmxcsr`/`ldmxcsr`도 번역합니다.
  * `rexbox_recomp`가 스레드를 초기화할 때 `g_mxcsr`를 0x1F80으로 둡니다.
* **`CVTSS2SI`/`CVTSD2SI`.** C 캐스트(버림)로 번역되던 것을 MXCSR 반올림 모드(기본 nearest-even)로 반올림합니다. 범위 밖의 값은 0x80000000입니다. 게임에 6곳이 있습니다.
* **upstream.** 이 lifter 수정은 열려 있던 PR [sp00nznet/xboxrecomp#198](https://github.com/sp00nznet/xboxrecomp/pull/198)에 합쳐 올렸습니다.
* **미번역 명령 분류.** 남은 34종 156곳은 지금 구성에서 하나도 실행되지 않습니다.
  * 147곳은 함수 안의 switch 표, 4곳은 DSOUND 객체, 2곳은 문자열입니다.
  * 3곳은 HLE로 대체된 D3D 함수만 닿는 하드웨어 접근입니다.
  * 자세한 내용은 [docs/analysis/unlifted-instructions.md](../analysis/unlifted-instructions.md)에 있습니다.

## reJSRF v0.0.20 (English)

Changes since **v0.0.19** (issue #48). **The `stmxcsr` untranslated-instruction warning printed every frame is gone, and SSE integer conversions round like the hardware.** The picture is the same as v0.0.19.

Resolved issue: #48, MXCSR modelled, `CVTSS2SI` rounding, unlifted instructions classified; commits `8bd968f`, `945b34a`, `ddf64f0`, `4cf509b`.

Changes:
* **MXCSR:** `sub_0015F0F0` stores MXCSR every frame and returns `E_UNEXPECTED` unless rounding is nearest. `stmxcsr` used to store nothing, so the check read whatever memory held.
  * The xboxrecomp fork (`rejsrf` `c345158`) keeps the guest MXCSR as TLS `g_mxcsr` (reset 0x1F80) and translates `stmxcsr`/`ldmxcsr`.
  * `rexbox_recomp` sets `g_mxcsr` to 0x1F80 when it initializes a thread.
* **`CVTSS2SI`/`CVTSD2SI`:** they were a C cast (truncation) and now round by the MXCSR rounding mode (nearest-even by default); out-of-range values give 0x80000000. The title has six such sites.
* **Upstream:** the lifter fix joined the open PR [sp00nznet/xboxrecomp#198](https://github.com/sp00nznet/xboxrecomp/pull/198).
* **Unlifted instructions:** none of the remaining 156 sites (34 kinds) runs in the current configuration.
  * 147 sites are switch tables inside functions, 4 a DSOUND object, and 2 a string.
  * 3 are hardware accesses reached only through HLE-replaced D3D functions.
  * Details: [docs/analysis/unlifted-instructions.md](../analysis/unlifted-instructions.md).

Verified:
* xboxrecomp: 469 tests pass on `rejsrf` and 520 on the PR #198 branch (`tools/recomp tools/disasm`); the `recomp_cvt_si32` runtime check passes with cl x86.
* Win32 x86 Release: regeneration and build with zero warnings; probes 56/0, 116/0, 48/0; d3d8 check 14,018/0; decomp check 6/0.
* Run: no untranslated-instruction warning up to frame 3,000; frames 300–3,000 (eight) byte-identical to v0.0.19.
