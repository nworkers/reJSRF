## reJSRF v0.0.47

이전 릴리스 **v0.0.46** 이후의 변경입니다(issue #102). **타이틀을 모르는 Xbox 런타임을 공용 저장소 [reexec/rexbox](https://github.com/reexec/rexbox)의 submodule로 씁니다.** reJSRF에는 타이틀 계층, 앱, 타이틀 도구만 남았습니다. 게임 동작과 생성 코드는 바뀌지 않았습니다.

### 바뀐 것

* **submodule**([설계 i102](../design/20261022-i102-rexbox-submodule.md))
  * `third_party/rexbox`(reexec/rexbox v0.0.9, `b2f2653`)를 더했다.
  * reJSRF 자체의 SDL, imgui, smaa, XbSymbolDatabase submodule은 지웠다. rexbox의 submodule이 같은 커밋을 가리킨다.
  * `third_party/xboxrecomp`(fork `rejsrf`, `5aae5df`)는 그대로다. 생성 코드는 v0.0.46과 같다.
* **지운 것**: `src/rexbox/`, `src/platform/`, `include/rexbox/`, `cmake/embed_text.cmake`, rexbox 도구·probe 다섯 개, `scripts/perf/`. 이것들은 이제 rexbox에 있다.
* **CMake**: `add_subdirectory(third_party/rexbox)`, `REXBOX_XBOXRECOMP_DIR`(reJSRF의 fork), `rexbox_add_recompiled_library`, rexbox의 라이선스 가드와 경고 설정. `REJSRF_VARIANT`(US판·일본판)는 그대로다.
* **스크립트**: `regenerate.py`, `find_pointer_targets.py`, `check_hle_pops.py`는 rexbox 스크립트를 부르는 wrapper가 되었다. 판 판단(MD5)과 지문 확인은 reJSRF에 남았다(`jsrf_variant.py`).
* **rexbox가 더한 것**: 커널 타이머(타이머가 실제로 울린다), D3D8 안개·정점 블렌딩, Swap 즉시 반환 등. 데모 3600프레임까지 화면은 같았다.
* **경로**: rexbox probe와 `rexbox_xdk_symbols`는 `build\win32_x86\third_party\rexbox\tools\<구성>\`에 생긴다.
* 빌드하는 쪽은 `git submodule update --init --recursive`가 필요하다. 지운 submodule의 옛 폴더(`third_party/SDL` 등)는 추적하지 않는 폴더로 남으므로 직접 지워도 된다.

## reJSRF v0.0.47 (English)

Changes since **v0.0.46** (issue #102). **The title-agnostic Xbox runtime is now the shared repository [reexec/rexbox](https://github.com/reexec/rexbox), used as a submodule.** reJSRF keeps only the title layer, the app and the title tools; game behaviour and the generated code are unchanged.

Resolved issue: #102, using the shared rexbox runtime as a submodule; commits `5beeb71` (design), `c649446` (implementation), `7b86ce7` (CI and a clean rebuild), `86d0820` (README build steps, AGENTS references).

Changes:
* **Submodule** ([design i102](../design/20261022-i102-rexbox-submodule.md))
  * `third_party/rexbox` (reexec/rexbox v0.0.9, `b2f2653`) was added.
  * reJSRF's own SDL, imgui, smaa and XbSymbolDatabase submodules were removed; rexbox's submodules point at the same commits.
  * `third_party/xboxrecomp` (fork `rejsrf`, `5aae5df`) is unchanged, so the generated code equals v0.0.46's.
* **Removed**: `src/rexbox/`, `src/platform/`, `include/rexbox/`, `cmake/embed_text.cmake`, the five rexbox tools and probes, `scripts/perf/`; they now live in rexbox.
* **CMake**: `add_subdirectory(third_party/rexbox)`, `REXBOX_XBOXRECOMP_DIR` (reJSRF's fork), `rexbox_add_recompiled_library`, rexbox's license guard and warning settings. `REJSRF_VARIANT` (US and Japanese builds) is unchanged.
* **Scripts**: `regenerate.py`, `find_pointer_targets.py` and `check_hle_pops.py` are wrappers around rexbox's scripts; build identification (MD5) and the fingerprint check stay in reJSRF (`jsrf_variant.py`).
* **What rexbox added**: kernel timers (timers now fire), D3D8 fog and vertex blending, an immediate Swap return and more; the demo looked the same up to frame 3600.
* **Paths**: the rexbox probes and `rexbox_xdk_symbols` are built under `build\win32_x86\third_party\rexbox\tools\<config>\`.
* Builders need `git submodule update --init --recursive`. The removed submodules' old folders (`third_party/SDL` and the like) stay behind as untracked folders and may be deleted by hand.

Verified: regeneration (US and Japanese) gives the same lifted code as v0.0.46 (only comment and scan-input differences), and the Japanese fingerprint check passes. Win32 x86 Release (US and Japanese) with zero warnings; kernel probe 94, dsound probe 55, D3D8 probe 220 with 0 failures; decomp check 129 and d3d8 check 14,018 cases with 0 differences. US demo frames 300-3600 and Japanese 300-1800, with the file-open lists, equal v0.0.46 byte for byte. CI: Debug and Release (with the Japanese app build) succeeded by hand on the branch and on the pull request. User: approved the merge.
