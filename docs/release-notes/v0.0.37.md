## reJSRF v0.0.37

이전 릴리스 **v0.0.36** 이후의 변경입니다(issue #84, #86). **Tab으로 여는 설정 메뉴와 Stats 창이 생겼고, 설정은 `rejsrf.ini`에 저장됩니다.**

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#84](https://github.com/nworkers/reJSRF/issues/84) | 설정 오버레이(Dear ImGui): Info·Graphics 탭, Stats 창(FPS·메모리·VRAM), `rejsrf.ini` | `b5fab1a`, `ef8fb61`, `6298f47`, `0daff02` |
| [#86](https://github.com/nworkers/reJSRF/issues/86) | 빌드 스크립트의 `.bat` 래퍼(PowerShell 실행 정책) | `0d3c9bd` |

새로 연 issue: [#85](https://github.com/nworkers/reJSRF/issues/85) Hor+ 와이드스크린. 이 게임은 Xbox 와이드 설정을 무시하므로 지금은 늘리기로 표시한다.

### 바뀐 것

* **설정 메뉴**([설계 i084](../design/20261017-i084-settings-overlay.md))
  * Tab(게임패드 LT+RT+Y)으로 연다. 메뉴가 열린 동안 게임은 계속 돌고 입력만 받지 않는다. 게임패드로 LT+RT+L3+R3을 1초 누르면 게임이 끝난다.
  * **Info 탭**: 버전, 빌드, 구성, 커밋, 게임, GL 드라이버, 표시 상태. 메모리(프로세스, 주소 공간, Xbox 메모리)와 VRAM(드라이버 보고값, 렌더 타깃·텍스처)도 보인다.
  * **Graphics 탭**: Rendering Resolution(1X~8X), Fullscreen, Widescreen(16:9 늘리기), VSync. Stats 창의 FPS·Memory·Video memory 체크박스.
  * OSD는 창 크기에 비례해 같은 비율을 유지한다.
* **Stats 창**
  * 체크한 섹션(FPS, Memory, Video memory)만 한 창에 이어 붙는다. 각각 현재 값과 최근 60초 그래프, 눈금 설명(FPS는 60 full speed / 30 half speed / 0 stopped)이 있다.
  * 그래프는 시간에 고정된 0.5초 칸이라 지난 값이 흔들리지 않는다.
  * 제목 표시줄로 옮기고(위치 저장), X로 닫는다.
* **설정 파일**
  * 실행 파일 옆 `rejsrf.ini`에 바꾸는 즉시 저장하고 시작할 때 읽는다. 단축키로 바뀐 값도 저장한다.
  * `REXBOX_RENDER_SCALE`, `REXBOX_VSYNC`가 있으면 그 실행에서만 이기고 파일에는 쓰지 않는다.
* **빌드**: `scripts\build_win32_x86.bat`이 실행 정책을 바꾸지 않고 빌드 스크립트를 실행한다(`scripts\build_win32_x86.bat Release`).
* **서드파티**: Dear ImGui v1.93.0(MIT, submodule `third_party/imgui`).

## reJSRF v0.0.37 (English)

Changes since **v0.0.36** (issues #84, #86). **A settings menu opened with Tab and a stats window; settings are saved in `rejsrf.ini`.**

Resolved issues:
* #84, the settings overlay (Dear ImGui): Info and Graphics tabs, the stats window (FPS, memory, VRAM), `rejsrf.ini`; commits `b5fab1a`, `ef8fb61`, `6298f47`, `0daff02`.
* #86, a `.bat` wrapper for the build script (PowerShell execution policy); commit `0d3c9bd`.

Opened: #85, Hor+ widescreen. The title ignores the Xbox widescreen setting, so the picture is stretched for now.

Changes:
* **Settings menu** ([design i084](../design/20261017-i084-settings-overlay.md))
  * Tab (LT+RT+Y on a gamepad) opens it. While it is open the game keeps running without input. LT+RT+L3+R3 held for a second on a gamepad quits.
  * **Info tab**: version, build, configuration, commit, game, GL driver, display state, memory (process, address space, Xbox memory) and VRAM (driver figures, render targets and textures).
  * **Graphics tab**: Rendering Resolution (1X to 8X), Fullscreen, Widescreen (stretched 16:9), VSync, and the stats window's FPS, Memory and Video memory checkboxes.
  * The OSD keeps the same proportion to the window.
* **Stats window**
  * Only the checked sections (FPS, Memory, Video memory) are stacked in one window, each with its current value, a graph of the last 60 seconds and labelled ticks (for FPS: 60 full speed / 30 half speed / 0 stopped).
  * The graphs use 0.5 s bins fixed in time, so past values do not shake.
  * It moves by its title bar (place saved) and closes with its close box.
* **Settings file**
  * `rejsrf.ini` next to the executable is saved on every change and read at start; hotkey changes are saved too.
  * `REXBOX_RENDER_SCALE` and `REXBOX_VSYNC`, when set, win for that run without being written.
* **Build**: `scripts\build_win32_x86.bat` runs the build script without changing the execution policy (`scripts\build_win32_x86.bat Release`).
* **Third party**: Dear ImGui v1.93.0 (MIT, submodule `third_party/imgui`).

Verified:
* Win32 x86 Debug and Release: zero build warnings; D3D8 probe 163/163; d3d8 check 14,018 cases with 0 differences; decomp check 129 cases with 0 differences.
* Behavior: hidden-window demo frame BMPs identical to v0.0.36; in a real window, the menu, saving and loading settings, widescreen, the stats window's three sections, steady graphs, dragging with the place saved, and the close box.
* User: the settings screens are in use; the gamepad combinations are not checked yet.
