## reJSRF v0.0.41

이전 릴리스 **v0.0.40** 이후의 변경입니다(issue #97). **Hor+ 와이드스크린에서 게임의 절두체 컬링이 넓어진 가로 시야를 따릅니다.** v0.0.40의 알려진 한계였던 가장자리 팝인이 없어집니다.

### 바뀐 것

* **절두체 컬링**([설계 i097](../design/20261018-i097-frustum-culling.md))
  * 게임의 카메라 절두체 설정 `sub_00153A90`을 디컴파일 어댑터(`src/game/jsrf/decomp/camera_frustum.c`)로 감싼다. 원본을 부른 뒤 와이드면 두 가시성 검사가 읽는 가로 tan/sec 전역에 W/640(16:9는 1.334, 21:9는 1.75)을 곱한다. 세로 값·깊이·투영 행렬은 그대로이고 HLE가 Hor+를 계속 처리한다. 4:3에서는 아무것도 쓰지 않는다.
  * 게임 라이브러리는 HLE를 직접 참조하지 않는다. `include/rejsrf/jsrf_host.h`의 C 훅 `rejsrf_host_horizontal_view_scale`(널이면 1)을 앱이 새 `rexbox_d3d8_horizontal_view_scale()`로 채운다. `rejsrf_decomp_check`는 그대로 HLE 없이 링크한다.
  * 빌드하는 쪽은 `scripts/recomp/regenerate.py`를 다시 돌려야 한다(`sub_00153A90_gen`이 새로 나온다).

## reJSRF v0.0.41 (English)

Changes since **v0.0.40** (issue #97). **The game's frustum culling follows the wider horizontal view of Hor+ widescreen**, removing the edge pop-in listed as a known limit in v0.0.40.

Resolved issue: #97, frustum culling for Hor+ widescreen; commits `6a3e6f4`, `0e868d6`.

Changes:
* **Frustum culling** ([design i097](../design/20261018-i097-frustum-culling.md))
  * The game's camera frustum setup `sub_00153A90` is wrapped by a decomp adapter (`src/game/jsrf/decomp/camera_frustum.c`): after the original, in wide mode the horizontal tan/sec globals read by the two visibility tests are scaled by W/640 (1.334 at 16:9, 1.75 at 21:9). The vertical values, the depth and the projection matrix stay, and the HLE keeps doing Hor+. Nothing is written at 4:3.
  * The game library does not reference the HLE: the C hook `rejsrf_host_horizontal_view_scale` in `include/rejsrf/jsrf_host.h` (null means 1) is filled by the app with the new `rexbox_d3d8_horizontal_view_scale()`; `rejsrf_decomp_check` still links without the HLE.
  * Builders must rerun `scripts/recomp/regenerate.py` (it now emits `sub_00153A90_gen`).

Verified: Win32 x86 Debug and Release with zero warnings; D3D8 probe 163/163; d3d8 check 14,018 cases with 0 differences; decomp check 129 cases with 0 differences. 4:3 demo frame 1500 byte-identical to v0.0.40; at 21:9 a temporary trace showed the adapter called about 460 times a second, horizontal tan × 1.75 and the vertical tan untouched. User: edge pop-in checked in 21:9 play.
