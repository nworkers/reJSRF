## reJSRF v0.0.14

이전 릴리스 **v0.0.13** 이후의 변경입니다(issue #35). **앱은 게임 디렉터리의 `default.xbe`를 읽고, 다른 XBE는 `--xbe <파일>`로 지정합니다.** 재컴파일 스크립트는 US판이 아닌 XBE를 읽으면 생성하지 않고 멈춥니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#35](https://github.com/nworkers/reJSRF/issues/35) | 게임 디렉터리의 `default.xbe`, 다른 XBE는 `--xbe`; 표기 통일; 생성 스크립트의 US판 MD5 검사 | `99e3247`, `409af30`, `28397e7`, `7927353` |

### 바뀐 것

* **실행 방법.**
  * `rejsrf.exe "roms\Jet Set Radio Future"`는 `default.xbe`를 읽는다.
  * 다른 XBE는 `--xbe`로 지정한다. 예를 들어 Sega GT·JSRF 합본 디스크라면 `--xbe SegaJSRF.xbe`다.
  * 읽은 XBE가 US판이면 실행한다. 지원하는 다른 판이면 읽기만 하고, `--xbe`로 US판을 지정하라는 안내와 함께 멈춘다.
  * v0.0.13의 자동 선택(폴더의 XBE 중 US판 찾기)은 없앴다.
* **잘못된 인자.**
  * 없는 파일은 폴더의 `.xbe` 목록과 함께 종료 코드 1로 끝난다.
  * 알 수 없는 옵션, 값 없는 `--xbe`, 남는 인자는 사용법과 함께 종료 코드 2로 끝난다.
* **생성 스크립트.** `regenerate.py`와 `find_pointer_targets.py`는 기본으로 `default.xbe`를 읽는다. 읽은 파일의 MD5를 `src/game/jsrf/recomp/variants.json`과 비교해, 다르면 생성하지 않고 멈춘다. seed와 타이틀 바인딩이 US판의 주소이기 때문이다.
* **문서.** US판과 일본판 모두 `default.xbe`로 표기하고, 지역과 MD5로 구분한다. **게임 폴더에는 US판을 `default.xbe`로 둔다.**

## reJSRF v0.0.14 (English)

Changes since **v0.0.13** (issue #35). **The app loads the game directory's `default.xbe`; `--xbe <file>` names another XBE.** The recompilation scripts stop without generating anything when the XBE is not the US build.

Resolved issue: #35, `default.xbe` from the game directory with `--xbe` for another XBE, unified naming, and the US MD5 check in the generation scripts. Commits `99e3247`, `409af30`, `28397e7` and `7927353`.

Changes:

* **How to run.**
  * `rejsrf.exe "roms\Jet Set Radio Future"` loads `default.xbe`.
  * `--xbe` names another XBE, for example `--xbe SegaJSRF.xbe` on a disc combining Sega GT and JSRF.
  * The US build runs. Another supported build is loaded, and the app stops with a hint to name the US XBE with `--xbe`.
  * v0.0.13's automatic choice (finding the US build among the folder's XBEs) is gone.
* **Malformed arguments.**
  * A missing file exits with 1, listing the folder's `.xbe` files.
  * An unknown option, `--xbe` without a value, or an extra argument prints the usage and exits with 2.
* **Generation scripts.** `regenerate.py` and `find_pointer_targets.py` read `default.xbe` by default. They compare its MD5 with `src/game/jsrf/recomp/variants.json` and stop without generating anything on a mismatch, because the seeds and title bindings are US addresses.
* **Docs.** Both the US and Japan builds are written as `default.xbe` and told apart by region and MD5. **Put the US build in the game folder as `default.xbe`.**

Verified:

* Win32 x86 Debug and Release: zero build warnings; d3d8 check 14,018 cases with 0 differences.
* Arguments:
  * no argument: 2
  * a file: 1
  * a directory without `default.xbe`: 1
  * a missing `--xbe` file: 1
  * malformed options: 2
  * the Japan build stops with the hint
  * the game directory reaches the attract demo
* Generation scripts: the US build passes; the Japan build and an unknown variant fail without generating anything.
