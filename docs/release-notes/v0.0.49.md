## reJSRF v0.0.49

이전 릴리스 **v0.0.48** 이후의 변경입니다(issue #113). **영어·일본어와 함께 한국어를 고를 수 있습니다.** 한국어는 [JSRF-kr-patch](https://github.com/nworkers/JSRF-kr-patch)로 자기 덤프에서 만든 한국어 게임 폴더를 영어 모드로 실행합니다. 저장소에는 게임 데이터나 패치 결과물이 없습니다.

### 바뀐 것

* **언어**([설계 i113](../design/20261023-i113-korean-language.md))
  * Game 탭과 `REJSRF_LANGUAGE`에 Korean이 생겼다. 한국어는 게임 언어 인덱스 1(영어)로 실행하고, 디스크(D:)를 한국어 폴더로 바꾼다. 그림과 음성은 영어판, 문장은 한국어다.
  * 한국어 폴더: `--korean <폴더>`, 없으면 `rejsrf.ini [Game] KoreanGameDirectory`, 둘 다 없으면 게임 폴더 옆의 `<게임 폴더>-kr`. 만드는 법은 [가이드](../guides/win32-setup-and-build.md)에 있다(`tools/patch.py … --link`).
  * 일본판 빌드는 Korean을 고를 수 없다(패치가 US판 기반).
* **XBE 검사**: 섹션 해시(64비트 FNV-1a, 해시만)로 원본, 한국어 패치(코드 같음, 문장 자료만 다름), 코드가 다른 XBE를 가린다. 코드가 다른 XBE는 lift된 코드와 맞지 않으므로 실행하지 않는다. 한국어 폴더가 없거나 맞지 않으면 영어로 시작하고 이유를 보인다. 패치 폴더를 게임 폴더로 바로 주면 한국어로만 실행한다.
* **HDD 캐시**: 원본 문장과 한국어 문장 사이를 바꾸면 그 실행에서 캐시 파티션(`hdd\Partition3`~`5`)을 비운다. 저장 데이터(`Partition1`)는 그대로다. 이 버전을 처음 실행할 때도 기록이 없어서 한 번 비운다.

## reJSRF v0.0.49 (English)

Changes since **v0.0.48** (issue #113). **Korean can be chosen beside English and Japanese.** Korean runs, in English mode, the Korean game folder made from your own dump with [JSRF-kr-patch](https://github.com/nworkers/JSRF-kr-patch); the repository holds no game data or patched output.

Resolved issue: #113, Korean beside English and Japanese; commits `ce4e8f0` (design) and `085e4ce` (implementation: the Korean folder, XBE checks, cache emptying, Game tab).

Changes:
* **Language** ([design i113](../design/20261023-i113-korean-language.md))
  * The Game tab and `REJSRF_LANGUAGE` gain Korean. It runs with the game's language index 1 (English) and swaps the disc (D:) for the Korean folder: English pictures and voice, Korean text.
  * The Korean folder: `--korean <folder>`, else `rejsrf.ini [Game] KoreanGameDirectory`, else `<game folder>-kr` beside the game folder. The [guide](../guides/win32-setup-and-build.md) shows how to make it (`tools/patch.py … --link`).
  * The Japanese build offers no Korean (the patch is based on the US build).
* **XBE checks**: section hashes (64-bit FNV-1a, hashes only) tell the original, the Korean patch (same code, only text data changed) and an XBE with changed code apart. Changed code would not match the lifted code and is refused. A missing or wrong Korean folder starts in English and says why; a patch folder given as the game folder runs in Korean only.
* **HDD cache**: switching between original and Korean text empties the cache partitions (`hdd\Partition3`-`5`) for that run; saves (`Partition1`) stay. The first run of this version empties them once too, since nothing is recorded yet.

Verified: Win32 x86 Release (US and Japanese) with zero warnings; rexbox probes 94/55/220 with 0 failures, decomp check 129 and d3d8 check 14,018 with 0 differences. The garage's first line shows in each language on one HDD (window captures), with the cache emptied only when switching between Korean and the original. Code-changed XBEs are refused; a missing folder and the Japanese build fall back with the reason. English and Japanese demo frames 300-1800 and file-open lists equal the previous build byte for byte. User: approved the merge.
