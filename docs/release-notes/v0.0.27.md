### 바뀐 것

* **즉시 모드.**
  * `SetVertexData2f`/`4f`는 레지스터 값을 정한다. 레지스터는 `D3DVSDE_*`이고, 프로그램이면 v0..v15다.
  * `D3DVSDE_VERTEX`에서 정점 하나가 확정된다.
  * `End`에서 정점을 현재 FVF 또는 선언의 배치로 묶어 기존 그리기 경로로 그린다.
* **그림자.** 게임은 이 경로로 스텐실 그림자 칠하기를 한다. 섀도 볼륨이 표시한 곳만 절반 어둡게 하는 사각형이다. 고가 구조물 아래 지면 등에 그림자가 나온다.
* **진단.** `REXBOX_D3D8_PROFILE` 보고에 `unimplemented per frame:` 줄이 생겼다. 미구현 경로마다 프레임당 호출 수를 보여 준다.

## reJSRF v0.0.27 (English)

Changes since **v0.0.26** (issue #62). **`Begin`/`End` immediate-mode drawing is implemented, and structure shadows (stencil) now show in the demo.**

Resolved issue: #62, D3D8 `Begin`/`End` immediate-mode drawing, commit `a06d1fc`.

Changes:
* **Immediate mode:**
  * `SetVertexData2f`/`4f` set register values. The registers are `D3DVSDE_*` values, or v0..v15 with a program.
  * `D3DVSDE_VERTEX` completes a vertex.
  * `End` packs the vertices in the current FVF or declaration layout and draws them through the existing path.
* **Shadows:** the game uses this path for its stencil shadow fill, a quad that halves the brightness only where the shadow volumes marked. Shadows show on the ground under the elevated structures and elsewhere.
* **Diagnostic:** the `REXBOX_D3D8_PROFILE` report gains an `unimplemented per frame:` line, giving calls per frame for each unimplemented path.

Verified:
* Win32 x86 Debug and Release: zero build warnings.
  * Probes: kernel 56/56, D3D8 135/135, DSOUND 48/48.
  * d3d8 check: 14,018 cases with 0 differences. decomp check: 6/6. HLE pop check: 0 mismatches.
* Behavior: structure shadows at demo frame 2,800; no `begin` in the unimplemented report.
* CI on the pull request.
