## reJSRF v0.0.15

이전 릴리스 **v0.0.14** 이후의 변경입니다(issue #37, #38). **오프닝(로고 뒤 3D 데모)에 캐릭터와 차량이 그려지고, 창의 X 버튼이나 Alt+F4로 앱이 종료됩니다.** D3D8 HLE가 정점 셰이더 프로그램(NV2A 마이크로코드)과 레지스터 컴바이너 픽셀 셰이더를 GLSL로 옮겨 그립니다. 그리기가 늘어 데모 구간은 Release에서 초당 8~10프레임입니다.

### 바뀐 것

* **정점 셰이더 프로그램.** 마이크로코드를 디코드해 GLSL로 옮깁니다(MAC·ILU 동시 실행, a0 상대 상수, 스키닝). 끝의 화면 공간 변환은 뷰포트 상수 `c[58]`/`c[59]`로 되돌립니다. 정점 선언(float, short, byte, D3DCOLOR)으로 속성을 묶습니다.
* **픽셀 셰이더.** `D3DPIXELSHADERDEF`를 `NV_register_combiners` 모델의 GLSL로 만듭니다. 정의 복사 크기를 0xF0으로 고쳤습니다.
* **창 닫기.** 창을 닫으면 D3D8 HLE가 런타임 종료 요청(`RequestExit`)을 보내고, 앱이 출력을 비운 뒤 종료합니다. 창 이벤트는 게임이 화면을 넘길 때 처리됩니다.
* **진단.** `REXBOX_SHADER_DUMP=1`은 게임이 만드는 정점 셰이더의 선언·디스어셈블과 픽셀 셰이더 정의를 출력합니다.
* **검사 도구.** `rexbox_d3d8_probe`에 35개 검사(모두 116개).
* **아직 안 되는 것.** 안개, 범프 맵 텍스처 모드(2D로 근사), 고정 기능 조명. 속도 개선은 다음 과제입니다.

## reJSRF v0.0.15 (English)

Changes since **v0.0.14** (issues #37 and #38). **The opening (the 3D demo after the logos) draws the characters and vehicles, and the window's X button or Alt+F4 ends the app.** The D3D8 HLE translates vertex-shader programs (NV2A microcode) and register-combiner pixel shaders to GLSL. With more drawing, the demo runs at 8–10 frames per second in Release.

Resolved issues: #37, characters in the opening (vertex-shader programs and combiner pixel shaders), commit `0404df8`; #38, closing the window (X button, Alt+F4) ends the process, commit `9f1f5df`.

Changes:
* **Vertex-shader programs:** the microcode is decoded and translated to GLSL (MAC and ILU in parallel, a0-relative constants, skinning). The trailing screen-space transform is undone with the viewport constants `c[58]`/`c[59]`, and attributes are bound from the vertex declaration (float, short, byte, D3DCOLOR).
* **Pixel shaders:** `D3DPIXELSHADERDEF` becomes GLSL on the `NV_register_combiners` model; the definition is now copied as 0xF0 bytes.
* **Closing the window:** the D3D8 HLE sends a runtime exit request (`RequestExit`), and the app flushes its output and exits; window events are handled when the game presents a frame.
* **Diagnostics:** `REXBOX_SHADER_DUMP=1` prints each created vertex shader's declaration and disassembly and each pixel shader's definition.
* **Tools:** 35 new checks in `rexbox_d3d8_probe` (116 in all).
* **Not yet:** fog, bump-map texture modes (approximated as 2D), fixed-function lighting. Speed is the next task.

Verified on Win32 x86 Debug and Release: zero build warnings; D3D8 probe 116/116, kernel probe 56/56, DSOUND probe 48/48; decomp check 6/6, d3d8 check 14,018 cases with 0 differences, 0 pop mismatches; characters and vehicles drawn at frames 2,800–3,400 of the opening; a windowed run given `WM_CLOSE` ends within 10 s; CI on the pull request.
