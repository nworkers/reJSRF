## reJSRF v0.0.4

이전 릴리스 **v0.0.3** 이후의 변경입니다(issue #12 진행분). **부팅이 D3D8 초기화와 게임의 객체 생성을 지나 커널 import 65 `IoCreateDevice`에서 멈춥니다.** 그 과정에서 재컴파일 파이프라인(xboxrecomp lifter)의 `lock xadd` 플래그 버그를 찾아 고치고 업스트림에 기여했습니다.

### 관련 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#12](https://github.com/nworkers/reJSRF/issues/12) (진행 중) | D3D8 HLE 두 번째 묶음: 리소스 모델, 서피스, 상태, 생성, 셰이더 핸들, 그리기 스텁; lifter `xadd` 수정 | `59c9731`, `7782a2f` |

issue #12의 목표(첫 `D3DDevice_Swap`)는 아직 도달하지 않아 issue는 열어 둡니다.

### 바뀐 것

* **D3D8 HLE.** export 8개 → 110개. Xbox `D3DResource` 헤더 레이아웃(`Common`/`Format`/`Size` 비트)을 그대로 쓰는 리소스 모델, 백버퍼·깊이 서피스, `Clear`/`Swap`, 렌더·텍스처 상태 저장, 텍스처·버퍼 생성과 Lock, `D3DResource_Register`, 셰이더 핸들, 그리기 스텁(로그만).
* **검증 도구.** `rejsrf_d3d8_check`가 리소스 헤더 케이스까지 13,557개를 lift 원본과 대조합니다. `scripts/recomp/check_hle_pops.py`는 export의 스택 pop 개수와 원본 `ret n`을 대조합니다.
* **진단.** `REXBOX_HLE_TRACE`(반환값 포함), `REXBOX_TRACE_MEMORY`, `REXBOX_WATCHDOG`(+`REXBOX_WATCHDOG_DUMP`), `REXBOX_HEAP_CHECK`, CMake `REJSRF_RECOMP_CALL_PROFILE`(직접 호출 프로파일).
* **xboxrecomp.** `lock xadd` 뒤의 조건 분기가 항상 거짓이 되어 COM `Release`가 객체를 두 번 해제하던 lifter 버그를 고쳤습니다. 업스트림 PR [sp00nznet/xboxrecomp#198](https://github.com/sp00nznet/xboxrecomp/pull/198)이 머지될 때까지 submodule은 포크 `nworkers/xboxrecomp`의 `fix/xadd-flags`를 가리킵니다. **기존 체크아웃은 `git submodule sync && git submodule update` 후 `regenerate.py`로 다시 생성해야 합니다.**

## reJSRF v0.0.4 (English)

Changes since **v0.0.3** (issue #12, in progress). **Boot now passes D3D8 initialization and the game's object setup and stops at kernel import 65 `IoCreateDevice`.** On the way, a `lock xadd` flags bug in the recompilation pipeline (the xboxrecomp lifter) was found, fixed and contributed upstream.

Related issue: #12 (in progress; its goal, the first `D3DDevice_Swap`, is not reached yet, so the issue stays open), commits `59c9731`, `7782a2f`.

Changes: the D3D8 HLE grew from 8 to 110 exports (a resource model using the Xbox `D3DResource` header layout, back-buffer and depth surfaces, `Clear`/`Swap`, stored render and texture state, texture and buffer creation and locking, `D3DResource_Register`, shader handles, logged drawing stubs); `rejsrf_d3d8_check` compares 13,557 cases with the lifted originals and `scripts/recomp/check_hle_pops.py` compares export pop counts with the originals' `ret n`; diagnostics `REXBOX_HLE_TRACE`, `REXBOX_TRACE_MEMORY`, `REXBOX_WATCHDOG` (+`REXBOX_WATCHDOG_DUMP`), `REXBOX_HEAP_CHECK` and the CMake option `REJSRF_RECOMP_CALL_PROFILE`; the xboxrecomp lifter fix (the conditional branch after `lock xadd` was always false, so COM `Release` freed objects twice), submitted upstream as [sp00nznet/xboxrecomp#198](https://github.com/sp00nznet/xboxrecomp/pull/198), with the submodule on the fork `nworkers/xboxrecomp` branch `fix/xadd-flags` until it is merged. **Existing checkouts need `git submodule sync && git submodule update` and a fresh `regenerate.py`.**

Verified on Win32 x86 Debug and Release: zero build warnings, kernel probe 27/27, decomp check 6/6, d3d8 check 13,557 cases with 0 differences, boot stopping at `IoCreateDevice`; xboxrecomp pytest 509 passed; CI on the pull request.
