이전 릴리스 **v0.0.12** 이후의 변경입니다(issue #31, #32, #33). **창이 rePIU처럼 동작합니다. 제목줄에 버전·빌드·FPS가 나오고, 2배 크기로 열리며, 배율과 전체화면을 단축키로 바꿉니다. 실행 인자는 게임 디렉터리입니다.** 첫 화면까지의 과정을 정리한 진행 기록과 스크린샷을 더했습니다.

### 바뀐 것

* **실행 방법.** `rejsrf.exe "roms\Jet Set Radio Future"`처럼 게임 디렉터리를 넘깁니다. 앱이 그 안의 `.xbe`를 내용으로 식별해 US판을 실행하고, 폴더를 게임의 `D:`로 씁니다. **XBE 경로를 넘기던 기존 명령은 오류(종료 코드 1)가 됩니다.**
* **창.**
  * 제목줄은 `reJSRF v0.0.13 (Win32/x86 Release) - Build <일시> - OpenGL 3.3 - FPS : 60.0` 꼴입니다.
  * 기본 크기는 1280x960이고, 종횡비를 지키며 크기를 바꾸거나 최대화할 수 있습니다.
  * Alt+1/2/3은 1~3배, 더블클릭과 Alt+Enter는 테두리 없는 전체화면입니다. Alt+Enter는 게임의 START로 가지 않습니다.
* **빌드.** 빌드 일시를 담은 헤더를 빌드마다 만듭니다. 분이 바뀔 때만 다시 씁니다.
* **문서.**
  * `docs/post/`: 진행 기록과 작성 지침.
  * `docs/screenshots/`: 실행 화면 11장과 캡처 방법.

## reJSRF v0.0.13 (English)

Changes since **v0.0.12** (issues #31, #32 and #33). **The window behaves like rePIU's: the title bar shows the version, build and FPS, the window opens at 2x, and shortcuts change the scale and fullscreen. The argument is now the game directory.** A progress post on the way to the first screen, with screenshots, was added.

Resolved issues:

* #31, a rePIU-style title bar (version, build time, FPS), a 2x resizable window, Alt+1/2/3 scales and borderless fullscreen, commit `7fe2e90`.
* #32, the progress post "From XBE to First Screen" with screenshots, commit `d23e701`.
* #33, the game directory as the argument instead of an XBE path, commit `13ec926`.

Changes:

* **How to run.** Pass the game directory, as in `rejsrf.exe "roms\Jet Set Radio Future"`. The app identifies the `.xbe` files in it by content, runs the US build and serves the folder as the game's `D:`. **The old command that passed an XBE path now fails with exit code 1.**
* **Window.**
  * The title bar reads `reJSRF v0.0.13 (Win32/x86 Release) - Build <time> - OpenGL 3.3 - FPS : 60.0`.
  * The default size is 1280x960. The window resizes and maximizes with its aspect ratio kept.
  * Alt+1/2/3 give 1x–3x. A double click or Alt+Enter toggles borderless fullscreen, and Alt+Enter does not reach the game as START.
* **Build.** A header with the build time is generated on every build and rewritten only when the minute changes.
* **Docs.**
  * `docs/post/`: the progress post and its writing guide.
  * `docs/screenshots/`: 11 screens and how they were taken.
  * README: the status and how to run.

Verified on Win32 x86 Debug and Release:

* Zero build warnings.
* Probes 56/56, 48/48 and 81/81.
* Window: the title and size of a real window; Alt+1/2/3, Alt+Enter and double click through synthesized input.
* Argument exit codes:
  * no argument: 2
  * a file: 1
  * a directory without an XBE: 1
  * a directory with only the Japan build: 0 (loaded, then stops)
* With the game directory, the boot reaches the attract demo.
