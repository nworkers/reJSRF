## reJSRF v0.0.54

이전 릴리스 **v0.0.53** 이후의 변경입니다(issue #124). **한국 정발 콤보 디스크(Sega GT 2002 + JSRF)의 `SegaJSRF.xbe`를 빌드 변형(`jsrf_bundle_kor`)으로 지원합니다.**

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#124](https://github.com/nworkers/reJSRF/issues/124) | 한국 정발 콤보 디스크(SegaJSRF.xbe) 빌드 변형 지원 | `3ddfd2a` |

### 바뀐 것

* **바이너리 분석 및 변형 지원**([20261026-i124](../design/20261026-i124-bundle-variant.md))
  * 한국 정발 콤보 디스크의 `SegaJSRF.xbe`(MD5 `8bf3c450e9c1cc39730d4025ef987e2c`)를 새 빌드 변형 `jsrf_bundle_kor`로 등록했습니다.
  * 세그먼트별 주소 이동 규칙(`va < 0x00074EC3`: 0, `0x00074EC3 <= va < 0x0018CB40`: `-0x30`, `va >= 0x0018CB40`: `-0x40`)을 규명하여 리프터 및 지문 검증에 적용했습니다.
  * 언어 변수(`0x001FC6E4`, 초깃값 `1`/English)를 확인하여 본편 텍스트가 영문으로 구성된 동작을 보존합니다.
* **지문 검증 및 리프터**
  * `scripts/recomp/variant_fingerprints.py`: 주소 변환기 `translate_va`를 구현하여 US판 기준 225개 핵심 함수의 지문이 100% 일치함을 검증했습니다.
  * `scripts/recomp/lifter.py`: 시드 주소, XDK extra 심볼 및 `overrides.c` 주소 변환을 적용했습니다.
* **디컴파일 함수 심볼 다형화**
  * C 전처리기 매크로 연쇄 확장 충돌을 방지하기 위해 `include/rejsrf/jsrf_addresses.h`에 `JSRF_DECOMP_XXXXXXXX` 고유 심볼을 도입하고 `mmatrix.c`, `camera_frustum.c`, `adxm_lock.c`에 적용했습니다.
* **빌드 시스템 및 앱**
  * `build_win32_x86.ps1`에 `-Variant bundle_kor`(별칭 `kor`)를 추가하여 `build\win32_x86_bundle_kor`에 빌드합니다.
  * `src/app/main.cpp`에서 디렉터리 경로를 지정했을 때 `default.xbe` 외에 `SegaJSRF.xbe`도 자동으로 탐색하도록 지원했습니다.

## reJSRF v0.0.54 (English)

Changes since **v0.0.53** (issue #124). **Adds support for `SegaJSRF.xbe` from the Korean combo disc (Sega GT 2002 + JSRF) as a build variant (`jsrf_bundle_kor`).**

### Resolved issue

| Issue | Description | Commit |
|---|---|---|
| [#124](https://github.com/nworkers/reJSRF/issues/124) | Korean combo disc (SegaJSRF.xbe) build variant support | `3ddfd2a` |

### Changes

* **Binary analysis and variant support** ([20261026-i124](../design/20261026-i124-bundle-variant.md))
  * Registered `SegaJSRF.xbe` (MD5 `8bf3c450e9c1cc39730d4025ef987e2c`) as the new build variant `jsrf_bundle_kor`.
  * Identified segmented address shifting rules (`va < 0x00074EC3`: 0, `0x00074EC3 <= va < 0x0018CB40`: `-0x30`, `va >= 0x0018CB40`: `-0x40`) applied to the lifter and fingerprint verification.
  * Confirmed the language global variable (`0x001FC6E4`, initial value `1`/English) to preserve English text display.
* **Fingerprint verification and lifter**
  * `scripts/recomp/variant_fingerprints.py`: Implemented `translate_va` and confirmed 100% (225/225) matching against US function fingerprints.
  * `scripts/recomp/lifter.py`: Applied address translation to seeds, XDK extra symbols, and `overrides.c`.
* **Decompiled function symbol polymorphism**
  * Introduced dedicated `JSRF_DECOMP_XXXXXXXX` tokens in `include/rejsrf/jsrf_addresses.h` to avoid preprocessor cascading macro expansion collisions, applied across `mmatrix.c`, `camera_frustum.c`, and `adxm_lock.c`.
* **Build system and app**
  * Added `-Variant bundle_kor` (alias `kor`) to `build_win32_x86.ps1`, outputting to `build\win32_x86_bundle_kor`.
  * Added auto-detection for `SegaJSRF.xbe` in `src/app/main.cpp` when specifying a game directory path.
