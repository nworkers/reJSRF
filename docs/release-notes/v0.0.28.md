## reJSRF v0.0.28 (English)

Changes since **v0.0.27** (issue #64). **Texture coordinate generation and texture transforms are implemented: the demo's environment maps, the characters' shading ramp and the scrolling textures now apply.**

Resolved issue: #64, D3D8 texture coordinate generation and texture transforms, commit `31bc440`.

Changes:
* **Per-stage coordinates:** with fixed-function vertex processing, the vertex shader makes each stage's coordinates.
  * Generation: camera-space normal, position or reflection vector.
  * Transform: `D3DTS_TEXTURE<s>` with `COUNTn` and `PROJECTED`.
  * Transformed 2D sets are padded D3D's way, `(u, v, 1, 0)`, which the game's scrolling matrices rely on.
* **Normals:** transformed by the inverse transpose of World·View, and normalized under `NORMALIZENORMALS`.
* **Vertex-program path:** unchanged.

Verified:
* Win32 x86 Debug and Release: zero build warnings.
  * Probes: kernel 56/56, D3D8 147/147, DSOUND 48/48.
  * d3d8 check: 14,018 cases with 0 differences. decomp check: 6/6. HLE pop check: 0 mismatches.
* Behavior: only `lighting` left in the unimplemented report; shading bands on the characters. CPU time, measured alternately against the previous build, differs by +0.4% (within the noise).
* CI on the pull request.
