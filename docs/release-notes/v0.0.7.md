## reJSRF v0.0.7

이전 릴리스 **v0.0.6** 이후의 변경입니다(issue #17). **DSOUND가 HLE로 바뀌어 부팅이 오디오 하드웨어(MCPX APU)를 읽지 않고 `DirectSoundCreate`를 지납니다.** 게임 스레드 4개가 돌고, 주 스레드가 `D:\Media\Sounds\dsstdfx.bin` 읽기의 완료 루틴(사용자 APC)을 기다리는 곳에서 멈춥니다. 게임이 버퍼를 만들기 전이라 아직 소리는 나지 않습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#17](https://github.com/nworkers/reJSRF/issues/17) | DSOUND HLE(SDL3 오디오 출력), 포인터로만 참조되는 함수 seed | `5bd62a8` |

### 바뀐 것

* **DSOUND HLE.** 게임이 부르는 함수 50개(`DirectSoundCreate`, `IDirectSound_*`, `IDirectSoundBuffer_*`). Lock·Unlock·Play·Stop·재생 위치·상태는 원본 코드에서 확인한 의미를 따릅니다. 믹서는 게스트 메모리의 버퍼를 직접 읽어 PCM 8/16비트와 Xbox ADPCM을 재생하고, 주파수·볼륨·루프 구간·믹스 빈을 반영합니다. `DownloadEffectsImage`는 `dsstdfx.bin`의 평문 효과 표로 서술자를 만들고, `GetEffectData`/`SetEffectData`는 효과 상태를 읽고 씁니다. 3D·엔벨로프·LFO·필터는 `S_OK`만 돌려줍니다.
* **플랫폼 오디오 계약.** `include/rexbox/platform/audio.h`, SDL3 구현(48 kHz 스테레오). 오디오 장치가 없거나 `REXBOX_AUDIO=none`이면 재생 위치가 실시간으로 움직이는 null 출력을 씁니다. `REXBOX_DSOUND_TRACE=1`은 버퍼 형식과 `Play`를 기록합니다.
* **놓친 함수.** `scripts/recomp/find_pointer_targets.py`가 데이터나 즉시값으로만 참조되는 함수(스레드 루틴, vtable 슬롯) 162개를 찾아 `seed_pointer_targets.json`에 넣습니다. lift 함수 8,852 → 9,015, 미해결 스텁 109 → 105.
* **검사 도구.** `rexbox_dsound_probe`(게임 데이터 불필요, CI). `check_hle_pops.py`가 DSOUND export도 대조합니다.
* **기존 체크아웃은 `regenerate.py`로 다시 생성해야 합니다.**

## reJSRF v0.0.7 (English)

Changes since **v0.0.6** (issue #17). **DSOUND now runs on HLE, so boot passes `DirectSoundCreate` without reading the audio hardware (MCPX APU).** Four game threads run, and the main thread stops waiting for the completion routine (a user APC) of its `D:\Media\Sounds\dsstdfx.bin` read. No sound plays yet because the game has not created buffers.

Resolved issue: #17, the DSOUND HLE (SDL3 audio output) and seeds for pointer-only functions, commit `5bd62a8`.

Changes: the DSOUND HLE (the 50 functions the game calls; Lock, Unlock, Play, Stop, cursors and status follow the semantics confirmed in the original code; a mixer reading buffers straight from guest memory plays 8/16-bit PCM and Xbox ADPCM with frequency, volume, loop region and mix bins; `DownloadEffectsImage` builds the descriptor from `dsstdfx.bin`'s plaintext effect table and `GetEffectData`/`SetEffectData` read and write effect state; 3D, envelopes, LFOs and filters return `S_OK`); the platform audio contract `include/rexbox/platform/audio.h` on SDL3 (48 kHz stereo), with a null output that keeps cursors moving in real time when there is no device or with `REXBOX_AUDIO=none`, and `REXBOX_DSOUND_TRACE=1` logging buffer formats and `Play`; `scripts/recomp/find_pointer_targets.py` seeding 162 functions referenced only from data or immediates (thread routines, vtable slots) into `seed_pointer_targets.json` (lifted functions 8,852 → 9,015, unresolved stubs 109 → 105); `rexbox_dsound_probe` (no game data, CI) and DSOUND coverage in `check_hle_pops.py`. **Existing checkouts need a fresh `regenerate.py`.**

Verified on Win32 x86 Debug and Release: zero build warnings, DSOUND probe 48/48, kernel probe 28/28, decomp check 6/6, d3d8 check 13,557 cases with 0 differences, 0 pop mismatches, no skipped indirect calls, stop at the APC wait of the `dsstdfx.bin` read; the host audio device opens at 48 kHz stereo; CI on the pull request.
