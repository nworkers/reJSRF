### 바뀐 것

* **DXT 압축 업로드**([설계 i088](../design/20261017-i088-dxt-compressed.md))
  * 호스트에 S3TC가 있으면 2D DXT1/3/5를 게스트 메모리 그대로 GPU에 올린다. 텍스처 VRAM이 데모 기준 70.7 MiB → 12.8 MiB.
  * `REXBOX_DXT=cpu`이면 예전처럼 CPU에서 푼다(비교용).
* **안티에일리어싱과 필터링**([설계 i089](../design/20261017-i089-anti-aliasing.md))
  * Graphics 탭 "Image quality": Anti-aliasing(Off, MSAA 2x~16x, SMAA 1x 중 하나)과 Anisotropic filtering(Off, 2x~16x).
  * MSAA는 모든 렌더 타깃을 멀티샘플로 만들고 읽을 때 resolve한다. GPU 한계를 넘는 값은 고를 수 없다.
  * SMAA 1x는 공식 SMAA(프리셋 High)를 최종 화면에 건다. 카툰 렌더링의 같은 밝기·다른 색상 경계를 잡도록 색 차이로 경계를 찾는다.
  * MSAA와 SMAA는 함께 쓰지 않는다. T2x·S2x·4x는 카툰 렌더링의 외곽선에 잔상을 남기거나 이득이 작아 넣지 않았다.
  * `rejsrf.ini`: `Msaa`, `Smaa`, `Anisotropy`. 둘 다 켜져 있으면 MSAA를 쓴다.
* **Window Size**([설계 i090](../design/20261017-i090-window-size.md)): Rendering Resolution 위. Alt+1/2/3과 같은 1x~3x 프리셋이고, 마지막 프리셋(`WindowScale`)이 다음 시작 때의 창 크기다.
* **정지 수정**([설계 i091](../design/20261018-i091-adxm-lock-priority.md)): 파일 캐시 미스 경로(`wxCiGetFileSize`)에서 SVM 잠금을 다 푸는 루프가 끝나지 않던 문제. #68의 호스트 잠금을 대기 중에 내려놓을 때 두 스레드가 엇갈려 나가면 전역 저장 우선순위가 섞였다. 이제 스레드마다 자기 우선순위로 돌아간다.
* **메뉴**: 탭을 바꿔도 창 높이가 가장 긴 탭에 맞춰 유지된다. 배수는 소문자 `x`로 쓴다.
* **서드파티**: SMAA(MIT, submodule `third_party/smaa`, `71c806a`).

## reJSRF v0.0.38 (English)

Changes since **v0.0.37** (issues #88, #89, #90, #91 and #84 follow-ups). **DXT textures go up compressed, cutting texture VRAM about 5.5x; MSAA, SMAA, anisotropic filtering and a Window Size setting are added; a hang in play caused by the CRI ADXM lock is fixed.**

Resolved issues:
* #88, compressed DXT upload through S3TC; commit `cd3626c`.
* #89, MSAA (2x-16x), SMAA 1x and anisotropic filtering (2x-16x); commits `308b17d`, `2e081f6`, `3dd476a`.
* #90, Window Size in the settings menu (1x-3x presets); commit `3dd476a`.
* #91, a stall where the CRI ADXM lock left a thread at TIME_CRITICAL; commit `4ec2bde`.
* #84 follow-ups, the menu keeps the tallest tab's height and multiples read `1x`-`8x`; commits `e260a7b`, `ff63a2c`, `b133ef1`.

Changes:
* **Compressed DXT upload** ([design i088](../design/20261017-i088-dxt-compressed.md))
  * With S3TC on the host, 2D DXT1/3/5 go to the GPU straight from guest memory. Texture VRAM in the demo drops from 70.7 MiB to 12.8 MiB.
  * `REXBOX_DXT=cpu` decodes on the CPU as before, for comparison.
* **Anti-aliasing and filtering** ([design i089](../design/20261017-i089-anti-aliasing.md))
  * The Graphics tab's "Image quality": Anti-aliasing (one of Off, MSAA 2x-16x, SMAA 1x) and Anisotropic filtering (Off, 2x-16x).
  * MSAA makes every render target multisampled and resolves it when read; values over the GPU's limit cannot be picked.
  * SMAA 1x runs the official SMAA (preset High) on the final picture, finding edges by color so the cel-shaded borders between areas of equal brightness and different hue are caught.
  * MSAA and SMAA are not combined. T2x, S2x and 4x are left out: they would ghost the cel-shaded outlines or gain little.
  * `rejsrf.ini`: `Msaa`, `Smaa`, `Anisotropy`; with both on, MSAA is used.
* **Window Size** ([design i090](../design/20261017-i090-window-size.md)): above Rendering Resolution; the 1x-3x presets Alt+1/2/3 give, and the last preset (`WindowScale`) is the window's size at the next start.
* **Hang fix** ([design i091](../design/20261018-i091-adxm-lock-priority.md)): the loop that releases every SVM lock on the file-cache-miss path (`wxCiGetFileSize`) never ended. When #68's host lock was put down during waits and two threads left out of order, the single saved priority got mixed; each thread now returns to its own priority.
* **Menu**: switching tabs keeps the tallest tab's height; multiples use a lowercase `x`.
* **Third party**: SMAA (MIT, submodule `third_party/smaa`, `71c806a`).

Known issue: in the user's setup the OSD once flashed with the game picture showing over it; it was not reproduced with the same settings (MSAA 2x at scale 4, SMAA) in the logo and demo sections.

Verified:
* Win32 x86 Debug and Release: zero build warnings; D3D8 probe 163/163; d3d8 check 14,018 cases with 0 differences; decomp check 129 cases with 0 differences.
* Behavior: in the hidden-window demo, frames with all AA off match v0.0.37 (before #91); after #91 the same scenes are a few frames apart, with no stall report. In a real window, MSAA 4x with AF 16x, SMAA 1x, and the Graphics tab (Window Size, Anti-aliasing).
* User: compressed DXT checked; AA, Window Size and #91 await play.
