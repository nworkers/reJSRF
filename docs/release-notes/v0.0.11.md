## reJSRF v0.0.11

이전 릴리스 **v0.0.10** 이후의 변경입니다(issue #25, #26, #27). **로고 시퀀스가 끝까지 나옵니다. SEGA → Smilebit → ADX → Dolby Digital → 낙서 경고문이 감마 램프 페이드와 함께 진행합니다.** 그 뒤 스테이지를 읽다가 게스트 메모리가 부족해 멈춥니다. 오디오 출력이 열리지만, 게임은 아직 `Play`를 부르지 않습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#25](https://github.com/nworkers/reJSRF/issues/25) | 오디오 출력 스레드 실패(64 MiB 기본 스택으로 주소 공간 고갈), 자기 일시정지 미처리 | `9df73b6` |
| [#26](https://github.com/nworkers/reJSRF/issues/26) | `SetGammaRamp`를 표시와 frame dump에 적용 | `9c1c11f` |
| [#27](https://github.com/nworkers/reJSRF/issues/27) | lifter의 `FCMOVcc` 번역 누락으로 로고 페이드가 끝나지 않음 | `84708d0` |

### 바뀐 것

* **링크 설정.** `rejsrf`는 `/STACK:64MB` 대신 `/LARGEADDRESSAWARE`로 링크합니다. 게스트 스레드는 64 MiB 스택을 명시적으로 받습니다. 오디오 출력이 열리고, 숨김 창 실행이 가끔 멈추던 문제도 사라졌습니다.
* **커널.** `NtSuspendThread`가 자기 자신을 대상으로 하면, 재개될 때까지 실제로 기다립니다(게임의 프레임 스레드가 매 프레임 이렇게 쉽니다).
* **D3D8.** Xbox `D3DGAMMARAMP`(768바이트)를 저장해 `GetGammaRamp`로 돌려주고, `Swap` 표시(단위 램프가 아니면 GLSL 조회)와 frame dump에 적용합니다.
* **xboxrecomp.** x87 `FCMOVcc` 여덟 가지를 조건부 이동으로 번역합니다. 업스트림 PR [sp00nznet/xboxrecomp#198](https://github.com/sp00nznet/xboxrecomp/pull/198)에 더했고, submodule은 포크 `rejsrf` 브랜치(`500de2b1`)를 가리킵니다. **기존 체크아웃은 `git submodule update` 후 `regenerate.py`를 다시 실행해야 합니다.**

## reJSRF v0.0.11 (English)

Changes since **v0.0.10** (issues #25, #26 and #27). **The logo sequence runs to the end: SEGA → Smilebit → ADX → Dolby Digital → the anti-graffiti notice, with gamma-ramp fades.** The boot then runs out of guest memory while loading the stage. The audio output opens, but the game calls no `Play` yet.

Resolved issues:

* #25, the audio output thread failing (address space exhausted by 64 MiB default stacks) and self-suspension not honored, commit `9df73b6`.
* #26, `SetGammaRamp` applied to the present and to frame dumps, commit `9c1c11f`.
* #27, the lifter's missing `FCMOVcc` keeping the logo fade from completing, commit `84708d0`.

Changes:

* **Link.** `rejsrf` links with `/LARGEADDRESSAWARE` instead of `/STACK:64MB`; guest threads get their 64 MiB stacks explicitly. This opens the audio output and removes the occasional hidden-window stall.
* **Kernel.** `NtSuspendThread` on the calling thread waits until resumed.
* **D3D8.** The Xbox `D3DGAMMARAMP` (768 bytes) is stored, returned by `GetGammaRamp`, and applied to the `Swap` present (a GLSL lookup unless identity) and to frame dumps.
* **xboxrecomp.** The eight x87 `FCMOVcc` forms are lifted as conditional moves. This was added to upstream PR [sp00nznet/xboxrecomp#198](https://github.com/sp00nznet/xboxrecomp/pull/198), and the submodule points at the fork branch `rejsrf` (`500de2b1`). **Existing checkouts need `git submodule update` and a fresh `regenerate.py`.**

Verified on Win32 x86 Debug and Release:

* Zero build warnings.
* Probes 42/42, 48/48 and 81/81.
* decomp check 6/6.
* d3d8 check 14,018 cases with 0 differences.
* 0 pop mismatches.
* xboxrecomp pytest: 513 passing.
* Boot: the five logos with fades, the audio output opened, guest memory running out after about 40 s.
