### 바뀐 것

* **정지 보고.** present가 정해진 시간(기본 10초) 동안 없으면, 게스트 스레드마다 다음을 stderr에 씁니다.
  * 마지막 HLE 호출: 이름, 호출한 곳, 경과 시간
  * 기다리는 중이면 대기 함수, 대상 객체와 그 객체의 현재 종류·신호 상태, 시한
  * 추정 호출 스택과 커널 스레드 상태
* **설정.**
  * present가 다시 오면 재개도 알립니다.
  * `REXBOX_STALL_REPORT=<초>`로 시간을 바꾸고 `0`으로 끕니다.
  * `REXBOX_STALL_DUMP=<파일>`이면 그때의 게스트 메모리(128 MiB)도 저장합니다.
* **구현.** 런타임의 `thread_activity`가 스레드별 마지막 HLE 호출과 대기를 기록합니다. 커널 대기·임계 구역·스레드 정지·D3D8 수직 동기 대기가 이를 알립니다.

## reJSRF v0.0.26 (English)

Changes since **v0.0.25** (issue #60). **When the picture stops (no present for a while), each guest thread's activity is reported once.**

Resolved issue: #60, report what each guest thread is doing when presents stop, commits `da1fb34` and `dcd46b9`.

Changes:
* **Stall report:** after a set time without a present (10 s by default), each guest thread's state goes to stderr:
  * its last HLE call: name, call site and elapsed time
  * when waiting: the wait function, the objects with their current kind and signal state, and the timeout
  * a guessed call stack and the kernel thread state
* **Settings:**
  * The resumption is reported when presents come back.
  * `REXBOX_STALL_REPORT=<seconds>` changes the time, and `0` turns the report off.
  * `REXBOX_STALL_DUMP=<file>` also saves the guest memory (128 MiB) at that moment.
* **Implementation:** the runtime's `thread_activity` records each thread's last HLE call and wait. Kernel waits, critical sections, thread suspension and the D3D8 vertical-blank waits report to it.

Verified:
* Win32 x86 Debug and Release: zero build warnings; kernel probe 56/56, D3D8 probe 116/116, DSOUND probe 48/48; d3d8 check 14,018 cases with 0 differences; decomp check 6/6.
* Behavior: no report and frame times within the noise in the default demo; one report and a resumption for an induced 2-second stall; no report with `REXBOX_STALL_REPORT=0`.
* CI on the pull request.
