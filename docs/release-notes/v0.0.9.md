## reJSRF v0.0.9

이전 릴리스 **v0.0.8** 이후의 변경입니다(issue #21). **장면 노드 순회의 `0x0FE80026` fault를 고쳐, 부팅이 fault 없이 프레임 루프를 계속 돕니다**(헤드리스 5분, 약 18만 5천 프레임). 그리기는 아직 받기만 하고, 게임은 사운드 버퍼를 만들지만 `Play`는 아직 부르지 않습니다.

### 바뀐 것

* **xboxrecomp 디스어셈블러.** 함수 경계가 확정된 뒤, 다른 함수 본문 중간을 가리키는 `jmp`/`jcc`를 alias 진입점으로 만듭니다. 전에는 반환 주소만 pop하는 스텁이 되어 스택이 어긋났습니다. 업스트림 PR [sp00nznet/xboxrecomp#200](https://github.com/sp00nznet/xboxrecomp/pull/200)으로 보냈고, submodule은 #198·#199·#200을 합친 포크 브랜치 `rejsrf`(`d79f8bb9`)를 가리킵니다.
* **생성 코드.** 분기 대상 48개 복구: lift 함수 9,193개, 미해결 스텁 105 → 83.
* **진단.** `REXBOX_FRAME_LOG=<n>`: n번째 present마다 프레임 수와 경과 시간 한 줄.
* **기존 체크아웃은 `git submodule update` 후 `regenerate.py`로 다시 생성해야 합니다.**

## reJSRF v0.0.9 (English)

Changes since **v0.0.8** (issue #21). **The `0x0FE80026` fault in the scene-node walk is fixed, so boot keeps running its frame loop with no fault** (5 minutes headless, about 185,000 frames). Drawing is still accepted but not drawn, and the game creates sound buffers but calls no `Play` yet.

Resolved issue: #21, the scene-node walk fault (branches into another function's interior become aliases, in xboxrecomp), commit `792d354`.

Changes: the xboxrecomp disassembler turns a `jmp`/`jcc` that points into another function's interior, once boundaries are final, into an alias entry instead of a stub that pops only the return address and skews the stack (upstream PR [sp00nznet/xboxrecomp#200](https://github.com/sp00nznet/xboxrecomp/pull/200); the submodule points at the fork branch `rejsrf` (`d79f8bb9`), which carries #198, #199 and #200); 48 targets recovered (9,193 lifted functions, unresolved stubs 105 → 83); the diagnostic `REXBOX_FRAME_LOG=<n>` prints the frame count and elapsed time every n presents. **Existing checkouts need `git submodule update` and a fresh `regenerate.py`.**

Verified on Win32 x86 Debug and Release: zero build warnings, kernel probe 42/42, DSOUND probe 48/48, decomp check 6/6, d3d8 check 13,557 cases with 0 differences, 0 pop mismatches, a 5-minute headless boot with no fault; xboxrecomp's pytest 522 passing; CI on the pull request.
