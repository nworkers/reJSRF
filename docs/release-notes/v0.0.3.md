## reJSRF v0.0.3

이전 릴리스 **v0.0.2** 이후의 변경입니다(issue #7). **부팅이 D3D8 디바이스 생성을 통과해 SDL3/OpenGL 창을 열고, 다음 미구현 함수 `D3DDevice_GetBackBuffer`에서 멈춥니다.** 어댑터·모드·Caps 질의 8개의 HLE 답은 원본 라이브러리와 일치함을 도구로 확인했습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#7](https://github.com/nworkers/reJSRF/issues/7) | D3D8 HLE 첫 묶음: SDL3 + OpenGL 호스트, 어댑터·모드·Caps 질의, `Direct3D_CreateDevice` | `3157c14`, `fc254dd` |

### 바뀐 것

* **표시 호스트 계층.** SDL3(release-3.4.18, zlib) submodule과 플랫폼 계약 `include/rexbox/platform/display.h`(창 + OpenGL 계열 컨텍스트, GL 함수 포인터, present). 구현은 `src/platform/sdl/`이며 모든 OS가 공유합니다. `REXBOX_DISPLAY=none`이면 창 없이 실행합니다.
* **D3D8 HLE.** `Direct3D_GetAdapterCount`, `D3D_GetAdapterModeCount`, `D3D_EnumAdapterModes`, `D3D_CheckDeviceFormat`, `Direct3D_CheckDeviceMultiSampleType`, `D3D_GetDeviceCaps`, `D3DDevice_GetDeviceCaps`, `Direct3D_CreateDevice`. 상수 표(모드 24개, Caps 53 DWORD, 포맷 능력 바이트)는 원본을 실행해 측정한 값입니다.
* **검증 도구 `rejsrf_d3d8_check`.** HLE export와 lift된 XDK 원본을 같은 게스트 상태에서 비교(eax, esp, 출력 버퍼). `--dump`는 원본의 답을 출력합니다.
* **규칙.** 여러 OS가 공유하는 호스트 라이브러리 백엔드는 `src/platform/<라이브러리>/`에 둡니다. 가져온 서드파티 코드의 문제는 업스트림에 기여하며, [re2DJ](https://github.com/reexec/re2DJ)(BSD-3-Clause)를 호스트 계층 참고 저장소로 추가했습니다.
* **문서.** `docs/kb/xbox-d3d8-api.md`, `docs/analysis/d3d8-adapter.md` 신설.

## reJSRF v0.0.3 (English)

Changes since **v0.0.2** (issue #7). **Boot now passes D3D8 device creation, opens the SDL3/OpenGL window and stops at the next unimplemented function, `D3DDevice_GetBackBuffer`.** The HLE answers of the eight adapter, mode and caps queries are confirmed by a tool to match the original library.

Resolved issue: #7, the first D3D8 HLE batch (SDL3 + OpenGL host, adapter/mode/caps queries, `Direct3D_CreateDevice`), `3157c14`, `fc254dd`.

Changes: the display host layer (SDL3 release-3.4.18 submodule, the platform contract `include/rexbox/platform/display.h` implemented in `src/platform/sdl/` for every OS; `REXBOX_DISPLAY=none` runs without a window); the D3D8 HLE exports `Direct3D_GetAdapterCount`, `D3D_GetAdapterModeCount`, `D3D_EnumAdapterModes`, `D3D_CheckDeviceFormat`, `Direct3D_CheckDeviceMultiSampleType`, `D3D_GetDeviceCaps`, `D3DDevice_GetDeviceCaps` and `Direct3D_CreateDevice`, with constant tables measured from the originals; the verification tool `rejsrf_d3d8_check` (HLE exports against the lifted XDK originals; `--dump` prints the originals' answers); the rule that shared host-library backends live in `src/platform/<library>/` and that problems in taken third-party code are contributed upstream, with [re2DJ](https://github.com/reexec/re2DJ) (BSD-3-Clause) added as a host-layer reference; new documents `docs/kb/xbox-d3d8-api.md` and `docs/analysis/d3d8-adapter.md`.

Verified on Win32 x86 Debug and Release: zero build warnings, `rexbox_kernel_probe` 27/27, `rejsrf_decomp_check` 6/6, `rejsrf_d3d8_check` 12,202 cases with 0 differences, boot opening the 640×480 OpenGL 3.3 window and stopping at `D3DDevice_GetBackBuffer`; CI (PR #11) passing Debug and Release with SDL and no generated code.
