## reJSRF v0.0.6

이전 릴리스 **v0.0.5** 이후의 변경입니다(issue #15). **XAPI 입력 API가 HLE로 바뀌어 부팅이 입력 초기화, 폰트 텍스처, 셰이더·버퍼 생성을 지나 `DirectSoundCreate`가 오디오 하드웨어(MCPX APU)를 읽는 곳까지 갑니다.** 부팅 중 건너뛰는 간접 호출은 0건입니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#15](https://github.com/nworkers/reJSRF/issues/15) | XInput HLE(SDL3 입력), 디스어셈블러·커널 수정 | `8549069` |

### 바뀐 것

* **XInput HLE.** `XInitDevices`, `XGetDevices`, `XGetDeviceChanges`, `XInputOpen/Close/GetCapabilities/GetState/SetState/Poll`, `XMountMUA`/`XUnmountMU`. 게임패드는 포트 0에 있고, 호스트 게임패드가 없으면 키보드로 입력합니다(방향키, Enter = START, Backspace = BACK, Z/X/C/V = A/B/X/Y, A/S = 트리거, Q/W = Black/White).
* **함수 단위 HLE 선택.** `hle_libraries.json`의 `functions`로 개별 XDK 함수를 고릅니다. 식별된 XDK 변수(장치 종류 등)는 타이틀 프로파일이 레지스트리에 바인딩합니다.
* **플랫폼 입력 계약.** `include/rexbox/platform/input.h`, SDL3 구현.
* **커널 HLE.** `ObDosDevicesDirectory()`/`ObWin32NamedObjectsDirectory()` 의사 핸들을 해석합니다(`D:\…` 파일 열기).
* **xboxrecomp.** 별칭 본문의 분기 대상이 빈 스텁이 되어 스택이 어긋나던 디스어셈블러 버그를 고쳐 업스트림 PR [sp00nznet/xboxrecomp#199](https://github.com/sp00nznet/xboxrecomp/pull/199)로 보냈습니다. submodule은 #198·#199를 합친 포크 브랜치 `rejsrf`를 가리킵니다. 미해결 스텁 184 → 109.
* **진단.** CMake `REJSRF_RECOMP_ABI_CHECK`(직접 호출마다 레지스터 보존·스택 확인), `REXBOX_WATCH32`, `REXBOX_PROFILE_ON_SKIP`, `REXBOX_SKIP_DUMP`, `REXBOX_STOP_DUMP`.
* **기존 체크아웃은 `git submodule sync && git submodule update` 후 `regenerate.py`로 다시 생성해야 합니다.**

## reJSRF v0.0.6 (English)

Changes since **v0.0.5** (issue #15). **The XAPI input API now runs on HLE, so boot passes input initialization, the font texture and shader and buffer creation and reaches `DirectSoundCreate` reading the audio hardware (MCPX APU).** No indirect call is skipped during boot.

Resolved issue: #15, the XInput HLE (SDL3 input) and the disassembler and kernel fixes, commit `8549069`.

Changes: the XInput HLE (`XInitDevices`, `XGetDevices`, `XGetDeviceChanges`, `XInputOpen/Close/GetCapabilities/GetState/SetState/Poll`, `XMountMUA`/`XUnmountMU`; a gamepad on port 0, with the keyboard as fallback: arrows, Enter = START, Backspace = BACK, Z/X/C/V = A/B/X/Y, A/S = triggers, Q/W = Black/White); per-function HLE selection through `functions` in `hle_libraries.json`, with identified XDK variables bound by the title profile; the platform input contract `include/rexbox/platform/input.h` on SDL3; the kernel HLE resolving the `ObDosDevicesDirectory()`/`ObWin32NamedObjectsDirectory()` pseudo-handles; the xboxrecomp disassembler fix for alias-body branch targets that became empty stubs (upstream PR [sp00nznet/xboxrecomp#199](https://github.com/sp00nznet/xboxrecomp/pull/199)), with the submodule on the fork branch `rejsrf` carrying #198 and #199 (unresolved stubs 184 → 109); diagnostics `REJSRF_RECOMP_ABI_CHECK`, `REXBOX_WATCH32`, `REXBOX_PROFILE_ON_SKIP`, `REXBOX_SKIP_DUMP`, `REXBOX_STOP_DUMP`. **Existing checkouts need `git submodule sync && git submodule update` and a fresh `regenerate.py`.**

Verified on Win32 x86 Debug and Release: zero build warnings, kernel probe 28/28, decomp check 6/6, d3d8 check 13,557 cases with 0 differences, no skipped indirect calls, stop at the APU access in `DirectSoundCreate`; xboxrecomp pytest passing; CI on the pull request.
