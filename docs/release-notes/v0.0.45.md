### 바뀐 것

* **검토**([20261020-i105](../design/20261020-i105-korean-patch-review.md))
  * 결론: 가능하다. reJSRF 런타임 안에서 문장과 글꼴을 바꾸는 방식을 권한다. 이 방식은 원본 파일을 고치지 않고 게임 자산을 배포하지 않는다.
  * 막는 것: 문자 코드 → 글리프 위치 대응(텍스트 렌더러 디컴파일 필요), 그림 속 글자. 가장 큰 일은 번역(일본어 약 27,000자)이다.
  * 구현은 하면 별도 프로젝트로 하며, 할지는 사용자가 정한다.
* **분석**([text-and-font](../analysis/text-and-font.md))
  * 화면 문장은 `Event/Event/e###.dat`(대사), `Mission/mssn####.bin`(미션), `TalkEvent`, `default.xbe`(메뉴·시스템·이름)에 있다.
  * 인코딩은 Shift-JIS이고 제어 코드 `$n`·`$r`·`$e` 등이 있다. 서로 다른 일본어 글자는 800자다.
  * `Font/jetfont.dat`는 DXT3 512×2304 글꼴 아틀라스(글리프 약 1,500개)다.
* 분석 스크립트 `scripts/analysis/text/find_text.py`, `text_records.py`.

## reJSRF v0.0.45 (English)

Changes since **v0.0.44** (issue #105). **A review of whether a Korean patch can be made**; no code changed, only analysis and review documents were added.

Resolved issue: #105, the Korean patch review (where the text lives, encoding, the font atlas, options, distribution and rights, effort); commit `4a204b7`.

Changes:
* **Review** ([20261020-i105](../design/20261020-i105-korean-patch-review.md))
  * Conclusion: feasible. Replacing text and font inside the reJSRF runtime is recommended; it leaves the original files untouched and ships no game assets.
  * Blockers: the character code → glyph slot mapping (needs the text renderer decompiled) and lettering in pictures. The largest piece of work is the translation (about 27,000 Japanese characters).
  * An implementation, if wanted, is a separate project; whether to do it is the user's call.
* **Analysis** ([text-and-font](../analysis/text-and-font.md))
  * On-screen text lives in `Event/Event/e###.dat` (dialogue), `Mission/mssn####.bin` (missions), `TalkEvent` and `default.xbe` (menus, system, names).
  * It is Shift-JIS with `$n`, `$r`, `$e` and other control codes, using 800 distinct Japanese characters.
  * `Font/jetfont.dat` is a DXT3 512×2304 glyph atlas (about 1,500 glyphs).
* Analysis scripts `scripts/analysis/text/find_text.py` and `text_records.py`.

Verified: no code changed (analysis scripts only). Text samples were decoded as CP932, and the glyphs were seen in the font's alpha image. User: approved the merge.
