# Work order: apply the D3D8 gamma ramp to the screen (issue #26)

Design: [20261013-i026](../design/20261013-i026-d3d8-gamma-ramp.md)

(1) `d3d8_gamma.h/.cpp` (pure): the 768-byte ramp, the identity test, CPU application and the present GLSL. (2) `d3d8_device.cpp`: `SetGammaRamp` (two arguments) stores the ramp, and `GetGammaRamp` returns it. (3) `d3d8_gl_targets`: `PresentRenderTarget` and `DumpRenderTarget` apply the ramp (a blit when it is identity). (4) Gamma cases in `rexbox_d3d8_probe`. (5) Verify: builds, probes, regression tools, fades in frame dumps. (6) Documents: kb (ramp layout), analysis (logo fades), ARCHITECTURE, the work log.
