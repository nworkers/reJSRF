# Work order: host vsync and aligning the virtual vblank clock (issue #82)

Design: [20261017-i082](../design/20261017-i082-vsync.md)

1. `include/rexbox/platform/display.h`: `VsyncMode`, `DisplayConfig.vsync`, `DisplayInfo.swap_interval`, `DisplayInfo.refresh_hz`.
2. `display_sdl.cpp`: apply the swap interval (0 for hidden windows, 1 when adaptive is refused), read the refresh (on creation, resize and monitor change).
3. `d3d8_device`: read `REXBOX_VSYNC`, report the result.
4. `d3d8_vblank`: a movable base time and `AlignVerticalBlank(t)`.
5. `d3d8_gl_targets`: time the swap in present and align when the conditions hold.
6. Verification: builds, regression tools, hidden-window demo BMP comparison. Documents: work log, guide, `ARCHITECTURE.md`.
