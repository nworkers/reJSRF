# 작업 지시: DSOUND HLE (issue #17)

설계: [20261012-i017](../design/20261012-i017-dsound-hle.md)

1. `hle_libraries.json`의 `functions`에 게임이 부르는 DSOUND 함수 50개를 더하고 재생성한다.
2. 플랫폼 오디오 계약 `include/rexbox/platform/audio.h`, SDL3 구현 `src/platform/sdl/audio_sdl.cpp`(장치 스트림 + null 출력 스레드). CMake의 SDL 오디오 하위 시스템은 이미 켜져 있다.
3. `rexbox_hle_dsound`를 파일로 나눈다: `dsound_hle.cpp`(등록, 출력 선택), `dsound_internal.h`(상수·배치·상태), `dsound_device.cpp`(DirectSound 객체·생성·캡·스피커·3D 리스너), `dsound_buffer.cpp`(버퍼 export), `dsound_effects.cpp`(효과 이미지), `dsound_mixer.cpp`(디코드·믹스·출력).
4. `rexbox_dsound_probe`(게임 데이터 불필요, CI): 수동 출력으로 설계 §8의 항목. `check_hle_pops.py`에 `dsound` 디렉터리.
5. 빌드(Debug/Release), 회귀 도구, `REXBOX_HLE_TRACE`와 `REXBOX_AUDIO=none`으로 부팅해 다음 frontier와 DSOUND 호출·버퍼 형식을 기록한다.
6. 문서: `docs/analysis/dsound.md`(확인됨/추정/미확정), `docs/kb/xbox-dsound.md`(+색인), `ARCHITECTURE.md`, boot-frontier, 가이드(`REXBOX_AUDIO`, 수동 확인), CI(새 probe), 작업 로그.

# Work order: DSOUND HLE (issue #17)

Design: [20261012-i017](../design/20261012-i017-dsound-hle.md)

(1) Add the 50 DSOUND functions the game calls to the `functions` list of `hle_libraries.json` and regenerate. (2) Platform audio contract `include/rexbox/platform/audio.h` with the SDL3 implementation `src/platform/sdl/audio_sdl.cpp` (device stream plus a null-output thread); SDL's audio subsystem is already enabled in CMake. (3) Split `rexbox_hle_dsound` into files: `dsound_hle.cpp` (registration, output choice), `dsound_internal.h` (constants, layouts, state), `dsound_device.cpp` (the DirectSound object, creation, caps, speakers, 3D listener), `dsound_buffer.cpp` (buffer exports), `dsound_effects.cpp` (effects image), `dsound_mixer.cpp` (decoding, mixing, output). (4) `rexbox_dsound_probe` (no game data, runs in CI): the items of design §8 with manual output; add the `dsound` directory to `check_hle_pops.py`. (5) Build Debug and Release, run the regression tools, boot with `REXBOX_HLE_TRACE` and `REXBOX_AUDIO=none`, and record the next frontier with the DSOUND calls and buffer formats. (6) Documents: `docs/analysis/dsound.md` (confirmed/assumed/open), `docs/kb/xbox-dsound.md` (and index), `ARCHITECTURE.md`, boot-frontier, the guide (`REXBOX_AUDIO`, manual check), CI (the new probe), the work log.
