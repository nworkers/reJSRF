# 작업 지시: XMM SSE2 intrinsic을 선택 사항으로 (issue #44 후속)

설계: [20261013-i044 §3.4](../design/20261013-i044-recomp-codegen.md)

1. `src/rexbox/CMakeLists.txt`에 `REXBOX_RECOMP_XMM_SSE2` 옵션(기본 `OFF`)을 둔다. `OFF`이면 `rexbox_recomp`에 `RECOMP_XMM_PORTABLE`를 PUBLIC으로 정의한다.
2. 생성 코드를 다시 만들고 Win32 Release를 빌드한다. 정의가 `rejsrf_recomp`까지 전달되는지 확인한다.
3. 회귀 도구를 돌리고, 숨긴 창으로 데모 구간(프레임 3,000)까지 실행한다.
4. 문서: 설계 §3.4, 작업 로그, ARCHITECTURE.md, frame-time 분석, Win32 빌드 가이드.
