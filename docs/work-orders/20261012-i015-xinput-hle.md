# Work order: XInput HLE (issue #15)

Design: [20261012-i015](../design/20261012-i015-xinput-hle.md)

(1) A `functions` list in `hle_libraries.json`; `regenerate.py` generates per-function overrides and the `rexbox_xdk_variables[]` table; the table type is declared in `recomp_hle_entry.h`. (2) `HleRegistry::BindVariable`/`FindVariable`; `rejsrf_game` exposes the table and `BindTitleHle` registers it. (3) Platform input contract `include/rexbox/platform/input.h` with the SDL3 implementation `src/platform/sdl/input_sdl.cpp` (gamepads plus the keyboard fallback). (4) `rexbox_hle_xinput`: the eleven exports of design §4, split into files (`xinput_hle.cpp` registration, `xinput_internal.h`, `xinput_devices.cpp`, `xinput_state.cpp`). (5) Regenerate, build Debug and Release, run the regression tools, boot with `REXBOX_HLE_TRACE` and record the next frontier. (6) Documents: `docs/kb/xbox-xinput.md` (and index), `ARCHITECTURE.md`, boot-frontier, the guide (keyboard map, manual check), the work log.
