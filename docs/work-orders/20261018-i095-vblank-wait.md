# Work order: VBlank wait on/off (issue #95)

Design: [20261018-i095](../design/20261018-i095-vblank-wait.md)

1. `d3d8_vblank`: the wait on/off, 10 kHz when off, `Retime` keeping the tick count, no alignment while off.
2. `d3d8_display`: `DisplayDefaults.vblank_wait` and the public functions.
3. The `VBlankWait` setting, applied at start, a Graphics tab checkbox.
4. Verification: builds, regression tools, fps and frame identity with it off, switching while running.
5. Documents: work log, guide, `ARCHITECTURE.md`.
