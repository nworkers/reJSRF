# Work order: moving to xboxrecomp v0.15.0 (issue #93)

Design: [20261020-i093](../design/20261020-i093-xboxrecomp-v0.15.md)

## A. xboxrecomp fork: table-entry recovery (upstream PR)

1. Branch `fix/table-entry-shapes` on the fork from v0.15.0 (`6376eb8`). Three commits: (a) the engine's `escapes` and table-arm exits plus `_probes_as_escaping_body`, (b) the byte-table and first-byte refusals, (c) `resync_jump_tables` stopping in front of a byte table. The trial patch (design 4.4) is carried over from the scratch worktree's diff.
2. A synthetic test per shape (in the style of `test_callback_cfg.py`): guarded vcall tail, a dispatcher into other functions, a `jmp` after a `jcc` to a helper outside the gap (accepted when proven, refused otherwise), a byte-table word refused, `resync_jump_tables` stopping.
3. `PYTHONUTF8=1 python -m pytest tools/disasm tools/recomp` all green.
4. Check on the JSRF disasm: 111 of the 113, the four demo addresses, no byte tables. List every difference against plain v0.15.0 (entries added and removed, functions whose end moved) and classify each one.
5. Open the upstream PR with the per-reason counts, the JSRF numbers and the no-regression argument (design section 5). Check for conflicts with a `work/v0.16.0` branch first, as happened with PR #200.

## B. Rebuilding the fork's `rejsrf`

1. `rejsrf-v0.15` on v0.15.0, in this order: A's branch → `perf/mem-base-local` → `perf/xmm-intrinsics` → `fix/fp-cc-cast` → `feat/stub-report` (rewritten: keep upstream's `RECOMP_STUB_HIT`; under `RECOMP_STUB_REPORT` route it to `recomp_unresolved_stub_log(va)`).
2. Compare the output with and without the six PR #200 commits on top; drop them if identical. If not, record the difference in the design and decide again.
3. Leave the old `rejsrf` as `rejsrf-v0.13`; move `rejsrf` to the new branch.

1. `recomp_abi.c`: define and reset `g_eflags`. `xbox_PortIn` / `xbox_PortOut` (reads 0, writes ignored, first access per port reported once). Read upstream's handling of the field pin `0x80C0` and decide.
2. Align `RECOMP_STUB_REPORT` in `src/game/jsrf/CMakeLists.txt` with B-1's rewrite.
3. Move the submodule to the new `rejsrf` and regenerate with `scripts/recomp/regenerate.py`. Compare the lift summary (unresolved stubs, the `RECOMP_UNIMPL` list) with today's (74). Check in the generated code whether the lifter's `_read_jump_table` reads a byte table as an arm.

5. User verification: the 95 s demo and the first New Game scene. 0 stub reports.
6. `--entry-stubs`: measure the generated code size and decide in a separate issue.
