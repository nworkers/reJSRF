# 작업 지시: 커널 HLE 최소 구현 (issue #3)

설계: [20261012-i003](../design/20261012-i003-kernel-hle.md)

1. 런타임 계약: `GuestCpu`, `GuestExecutor`, `Environment`, `HleCall`, `GuestHeap`(페이지 할당자).
2. 플랫폼: `CreateHostThread`(스택 크기 지정), 대기 가능한 스레드 핸들.
3. `rexbox_recomp`: `RecompExecutor`(레지스터 접근, 스레드 시작·종료, 스레드별 보고), 앱의 "모든 게스트 스레드 대기".
4. 커널 HLE: KPCR/ETHREAD 생성, `PsCreateSystemThreadEx`/`PsTerminateSystemThread`, 데이터 export, 디스패처 객체와 대기, 이후 부팅이 닿는 서비스(메모리, 동기화, 파일, Rtl, HAL)를 순서대로.
5. 시험 도구 `rexbox_kernel_probe`(디스패처 객체).
6. 문서: 부팅 frontier 갱신, `docs/kb/`(Xbox 커널 구조), ARCHITECTURE, 작업 로그.
7. 검증: 설계 §7.

완료 기준: 부팅이 게임 메인 스레드로 들어가 커널 외부의 다음 frontier(XDK·하드웨어·자산 단계)에 도달하거나, 남은 커널 blocker가 문서로 특정된다.

# Work order: minimal kernel HLE (issue #3)

Design: [20261012-i003](../design/20261012-i003-kernel-hle.md)

(1) Runtime contracts: `GuestCpu`, `GuestExecutor`, `Environment`, `HleCall`, `GuestHeap` (page allocator). (2) Platform: `CreateHostThread` (with a stack size) and joinable thread handles. (3) `rexbox_recomp`: `RecompExecutor` (register access, thread start and exit, per-thread reports); the app waits for all guest threads. (4) Kernel HLE: KPCR/ETHREAD creation, `PsCreateSystemThreadEx`/`PsTerminateSystemThread`, data exports, dispatcher objects and waits, then the services boot reaches (memory, sync, files, Rtl, HAL) in order. (5) Test tool `rexbox_kernel_probe` (dispatcher objects). (6) Docs: boot frontier, `docs/kb/` (Xbox kernel structures), ARCHITECTURE, work log. (7) Verify: design §7.

Done when boot enters the game's main thread and reaches the next frontier outside the kernel (XDK, hardware or asset stage), or the remaining kernel blockers are pinned down in the docs.
