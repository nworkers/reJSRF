# 작업 지시: 커널 HLE 사용자 APC (issue #19)

설계: [20261012-i019](../design/20261012-i019-user-apc.md)

1. `KernelThread`에 사용자 APC 큐, 게스트 스레드가 아닐 때의 `thread_local` 기록, 큐 넣기·꺼내기·실행 도우미(`kernel_apc.cpp`).
2. 파일 I/O export 5개가 오류 아닌 완료에서 `ApcRoutine`을 큐에 넣는다.
3. 대기 5종(`NtWaitForSingleObject`, `NtWaitForSingleObjectEx`, `NtWaitForMultipleObjectsEx`, `KeWaitForSingleObject`, `KeDelayExecutionThread`)의 경고 가능 사용자 모드 대기에서 APC 전달과 `STATUS_USER_APC`.
4. `NtUserIoApcDispatcher`(ordinal 232)와 공용 `NtStatusToDosError` 도우미.
5. `rexbox_kernel_probe`에 APC 검사(가짜 실행기의 `CallGuest`가 레지스트리로 루틴을 찾게).
6. 빌드(Debug/Release), 회귀 도구, 부팅으로 다음 frontier 기록.
7. 문서: `docs/kb/xbox-kernel-structures.md`(APC 절), `docs/analysis/boot-frontier.md`, `docs/analysis/dsound.md`(실행에서 본 효과 이미지·버퍼), `ARCHITECTURE.md`, 가이드, 작업 로그.

# Work order: kernel HLE user APCs (issue #19)

Design: [20261012-i019](../design/20261012-i019-user-apc.md)

(1) A user APC queue on `KernelThread`, a `thread_local` record for threads that are not guest threads, and helpers to queue, take and run APCs (`kernel_apc.cpp`). (2) The five file I/O exports queue their `ApcRoutine` on a completion that is not an error. (3) The five waits (`NtWaitForSingleObject`, `NtWaitForSingleObjectEx`, `NtWaitForMultipleObjectsEx`, `KeWaitForSingleObject`, `KeDelayExecutionThread`) deliver APCs and return `STATUS_USER_APC` in alertable user-mode waits. (4) `NtUserIoApcDispatcher` (ordinal 232) and a shared `NtStatusToDosError` helper. (5) APC checks in `rexbox_kernel_probe` (the fake executor's `CallGuest` finds routines through the registry). (6) Build Debug and Release, run the regression tools, boot and record the next frontier. (7) Documents: `docs/kb/xbox-kernel-structures.md` (an APC section), `docs/analysis/boot-frontier.md`, `docs/analysis/dsound.md` (the effects image and buffers seen in a run), `ARCHITECTURE.md`, the guide, the work log.
