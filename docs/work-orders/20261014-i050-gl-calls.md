# 작업 지시: 그리기마다의 GL 호출 줄이기 (issue #50)

설계: [20261014-i050](../design/20261014-i050-gl-calls.md)

1. `REXBOX_GL_CALLS=1` 진단: GL 함수 표 항목마다 호출 계수 래퍼를 두고, 프로파일 보고에 프레임당 호출 수를 함수별로 낸다.
2. 데모 구간의 호출 수를 기준으로 잰다.
3. 정점 속성 상태 캐시(`SetAttribute`/`FinishAttributes`), 프레임버퍼 바인딩 기억, 정점 상수를 location run마다 한 번에 보내기.
4. 호출 수, 프레임 덤프, 기준과 번갈아 잰 CPU 시간으로 확인한다.
5. Debug/Release 빌드, 회귀 도구, 문서(가이드, ARCHITECTURE, frame-time, 작업 로그).

# Work order: fewer GL calls per draw (issue #50)

Design: [20261014-i050](../design/20261014-i050-gl-calls.md)

1. `REXBOX_GL_CALLS=1` diagnostic: a counting wrapper per GL function-table entry, with calls per frame by function in the profile report.
2. Measure the baseline call counts in the demo window.
3. A vertex-attribute state cache (`SetAttribute`/`FinishAttributes`), a remembered framebuffer binding, and vertex constants sent once per location run.
4. Check call counts, frame dumps, and CPU time in runs alternating with the baseline.
5. Debug and Release builds, regression tools, documents (guide, ARCHITECTURE, frame-time, work log).
