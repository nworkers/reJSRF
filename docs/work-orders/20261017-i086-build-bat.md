# Work order: a .bat wrapper for the build script (issue #86)

PowerShell's default execution policy blocks `scripts\build_win32_x86.ps1`; make it runnable without changing the policy. No design change.

1. `scripts\build_win32_x86.bat`: `powershell -NoProfile -ExecutionPolicy Bypass -File build_win32_x86.ps1 <arguments>`. Arguments pass through, `-Configuration` is added when the first one is a configuration name, and the exit code is returned.
2. Usage in the guide and README.
3. Verification: a Release build through the `.bat`.
