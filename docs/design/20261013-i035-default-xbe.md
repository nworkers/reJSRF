# 설계: 게임 디렉터리의 default.xbe, 다른 XBE는 --xbe (issue #35)

선행: [i033](20261013-i033-game-directory-argument.md)(이 설계가 §1의 XBE 고르기를 대체한다)

## 1. 결정

* Xbox 타이틀의 기본 실행 파일은 `default.xbe`이고, 대시보드도 이 파일을 실행한다. 앱도 같은 규칙을 따른다.
  * `rejsrf <게임 디렉터리>`는 `<게임 디렉터리>\default.xbe`를 읽는다.
  * 다른 XBE는 `--xbe <파일>`(또는 `--xbe=<파일>`)로 지정한다. 파일은 게임 디렉터리 기준이다. 예를 들어 Sega GT와 JSRF를 함께 담은 합본 디스크라면 `--xbe SegaJSRF.xbe`다.
* i033의 "디렉터리의 XBE를 모두 읽어 US판을 고른다"는 없앤다. 앱이 실행 파일을 임의로 고르지 않는다.
* 읽은 XBE의 식별은 그대로다.
  * US판(주 변형)이면 실행한다.
  * 지원하는 다른 판이면 읽기만 하고 멈춘다. 이때 `--xbe`로 US판을 지정하라는 안내를 출력한다.
  * 지원하지 않는 XBE는 종료 코드 1이다.
* 오류 처리:
  * 파일이 없으면 디렉터리에 있는 `.xbe` 목록과 함께 종료 코드 1로 끝난다.
  * 알 수 없는 옵션, 값 없는 `--xbe`, 남는 인자는 사용법과 함께 종료 코드 2로 끝난다.
* 문서의 예시 파일 이름은 `SegaJSRF.xbe`처럼 합본 디스크를 떠올리게 하는 이름을 쓴다. 재컴파일 코드는 US판에서 만들었으므로, `default.xbe`가 다른 판이면 US판 XBE를 `--xbe`로 지정해야 한다. 가이드가 이를 밝힌다.

* **생성 스크립트의 US판 검사**:
  * `regenerate.py`와 `find_pointer_targets.py`의 기본 XBE도 `default.xbe`다.
  * 두 스크립트는 읽은 XBE의 MD5를 `src/game/jsrf/recomp/variants.json`(variant별 레이블과 MD5)과 비교하고, 다르면 생성하지 않고 멈춘다. seed, 타이틀 바인딩, 디컴파일 함수가 US판의 주소이므로, 다른 판을 읽으면 맞지 않는 코드가 조용히 생기기 때문이다.
  * 검사는 `scripts/recomp/xbe_variant.py` 하나에 둔다.
  * `rejsrf_d3d8_check`는 이미 인증서로 US판인지 확인한다.

## 2. 검증

인자별 기대 결과:

# Design: default.xbe from the game directory, --xbe for another XBE (issue #35)

Prerequisite: [i033](20261013-i033-game-directory-argument.md). This design replaces how §1 there picks the XBE.

## 1. Decisions

* An Xbox title's default executable is `default.xbe`, which the dashboard launches, and the app follows the same rule.
  * `rejsrf <game directory>` loads `<game directory>\default.xbe`.
  * `--xbe <file>` (or `--xbe=<file>`) names another XBE, relative to the game directory. For example, `--xbe SegaJSRF.xbe` on a disc that carries Sega GT and JSRF together.
* i033's "read every XBE in the directory and pick the US build" is dropped. The app does not choose the executable by itself.
* The loaded XBE is still identified:
  * The US build (the primary variant) runs.
  * Another supported build is loaded and the app stops, with a hint to name the US XBE with `--xbe`.
  * An unsupported XBE exits with code 1.
* Errors:
  * A missing file exits with code 1, listing the `.xbe` files in the directory.
  * An unknown option, `--xbe` without a value, or an extra argument prints the usage and exits with code 2.
* The docs' example file name is one like `SegaJSRF.xbe`, which suggests a combined disc. The recompiled code comes from the US build, so when `default.xbe` is another build the US XBE must be named with `--xbe`, and the guide says so.

* **US check in the generation scripts.**
  * `regenerate.py` and `find_pointer_targets.py` also default to `default.xbe`.
  * Both compare the XBE's MD5 with `src/game/jsrf/recomp/variants.json` (a label and an MD5 per variant) and stop without generating anything on a mismatch. The seeds, title bindings and decompiled functions hold US addresses, so another build would silently produce code that does not match them.
  * The check lives in `scripts/recomp/xbe_variant.py`.
  * `rejsrf_d3d8_check` already checks the certificate for the US build.

## 2. Verification

Expected results by argument:

| Argument | Result |
|---|---|
| none | 2 |
| a file | 1 |
| a directory without `default.xbe` | 1 |
| the game directory (US `default.xbe`) | reaches the attract demo |
| `--xbe` naming a Japan XBE | loads it, prints the hint, stops with 0 |
| `--xbe` naming a missing file | 1, with the list |
| `--xbe` without a value | 2 |
| an unknown option | 2 |
| an extra argument | 2 |
