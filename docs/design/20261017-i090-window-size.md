# 설계: 설정 메뉴의 Window Size (issue #90)

## 1. 목표

설정 메뉴 Graphics 탭의 Rendering Resolution 위에 Window Size를 둔다. 값은 지금 Alt+1/2/3이 주는 프리셋(그림의 1x, 2x, 3x)만이다. 마지막으로 고른 프리셋은 `rejsrf.ini`에 저장해 다음 시작 때의 창 크기로 쓴다.

## 2. 설계

* 플랫폼(`display.h`, SDL 구현)
  * `kMaxWindowScale = 3`.
  * `SetWindowScale(scale)`: Alt+1/2/3과 같은 `ApplyScale`이다. 전체화면이나 최대화를 먼저 풀고 그림 크기 × 배율로 맞춘다.
  * `WindowScale()`: 창이 지금 프리셋 크기와 정확히 같으면 그 배율, 아니면 0이다(손으로 크기를 바꿨거나, 최대화·전체화면이거나, 창이 없을 때).
  * `GetPictureSize()`: 프리셋이 곱하는 그림 크기다(4:3이면 640x480, Widescreen이면 854x480).
* 시작 크기: `DisplayDefaults.window_scale`(기본 2) → `DisplayConfig.scale`.
* 설정 파일: `WindowScale = 1|2|3`.
* 메뉴
  * 콤보 "Window Size"의 항목은 `1x (640x480)`, `2x (1280x960)`, `3x (1920x1440)`이다(Widescreen이면 너비가 854의 배수).
  * 지금 크기가 프리셋이 아니면 미리보기에 `Custom`, 전체화면이면 `Fullscreen`을 보인다.
  * 프리셋을 고르면 전체화면이 풀린다(Fullscreen 설정도 끈다).
  * Alt+1/2/3으로 바꾼 크기도 메뉴가 관찰해 저장한다. 손으로 바꾼 크기(0)는 저장하지 않고 마지막 프리셋을 둔다.

## 3. 하지 않는 것

* 3x보다 큰 프리셋, 임의 크기 입력, 창 위치 저장.

# Design: Window Size in the settings menu (issue #90)

## 1. Goal

Add Window Size above Rendering Resolution in the settings menu's Graphics tab. Its values are only the presets Alt+1/2/3 give today (the picture at 1x, 2x, 3x). The last preset picked is saved in `rejsrf.ini` and used as the window's size at the next start.

## 2. Design

* Platform (`display.h`, the SDL implementation)
  * `kMaxWindowScale = 3`.
  * `SetWindowScale(scale)`: the same `ApplyScale` as Alt+1/2/3. It leaves fullscreen or a maximized window first, then sizes the window to the picture times the scale.
  * `WindowScale()`: the scale when the window is exactly a preset's size, else 0 (resized by hand, maximized, fullscreen, or no window).
  * `GetPictureSize()`: the picture size the presets multiply (640x480 at 4:3, 854x480 with Widescreen).
* Starting size: `DisplayDefaults.window_scale` (default 2) → `DisplayConfig.scale`.
* Settings file: `WindowScale = 1|2|3`.
* Menu
  * The "Window Size" combo lists `1x (640x480)`, `2x (1280x960)`, `3x (1920x1440)` (with Widescreen, widths are multiples of 854).
  * When the size is not a preset, the preview reads `Custom`; in fullscreen it reads `Fullscreen`.
  * Picking a preset leaves fullscreen (the Fullscreen setting turns off too).
  * The menu also observes and saves sizes set with Alt+1/2/3. A size set by hand (0) is not saved; the last preset stays.

## 3. Not done

* Presets above 3x, typing a size, saving the window's position.
